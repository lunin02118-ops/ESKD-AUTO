## 🚀 Ключевые возможности

- **Безчертёжные детали (БЧ)** — кнопка «Деталь БЧ» на вкладке ЕСКД (контекст детали): помечает деталь как безчертёжную по ГОСТ 2.109 (свойство-признак «БЧ», индекс « БЧ» в наименовании — запись попадает в спецификацию; повторное нажатие снимает признак). В базе ТТ — раздел «$$$12. Безчертёжные детали (БЧ)».

* **Полная автоматизация основной надписи (штампа ГОСТ 2.104)**: автоматическое считывание децимального номера, наименования, литеры, массы, масштаба и фамилий разработчиков из свойств модели.
* **Двухэтажные дроби сортамента по ГОСТ**: нативное формирование дроби с чертой (тег `<STACK>верх<OVER>низ</STACK>`) для листового, сортового и трубного проката при назначении материалов.
* **Гарантия неизменности чертежей (Zero-Drift)**: физические координаты надписей и линий штампа зафиксированы с абсолютной точностью ($\Delta = 0.0000$ мм при сохранении чертежа).
* **Сквозная совместимость с пакетом SWPlus (MProp, SProp, DProp)**: прозрачная синхронизация свойств (`Контора`, `Организация`, `Разраб.`) во всех конфигурациях без конфликтов.
* **Защита стандартных и покупных деталей**: изделия из баз `SProp`, каталогов поставщиков и SolidWorks Toolbox защищены от перезаписи наименования, шифра и свойств при фоновом автосохранении.
* **Высокопроизводительное сохранение сборок**: сохранение корневого документа сборки без рекурсивного сканирования сотен дочерних подсборок и деталей.
* **Векторный экспорт в PDF**: формирование векторных PDF-документов встроенными средствами SolidWorks API без необходимости сторонних виртуальных принтеров.
* **Автоматизация черчения Drw (Drew)**: модуль автоматической компоновки проекций, масштабирования и расстановки размеров.
* **Развертывание рабочего места за 1 клик**: конфигурационный PowerShell-скрипт настраивает реестр SolidWorks, пути к шаблонам, шрифты ГОСТ и панели инструментов.

## ⚡ Быстрый старт (Развертывание в 1 клик)

### Системные требования
* **ОС**: Windows 10 / Windows 11 (x64).
* **САПР**: SolidWorks 2018, 2019, 2020, 2021, 2022, 2023, 2024, **2025 SP0+**. Полная автоматическая настройка рабочего места верифицирована на SolidWorks 2025; скрипт развертывания поддерживает автодетект установленной версии (2018–2025), корпоративный реестровый профиль поставляется для SW2025.
* **Среда выполнения**: Microsoft .NET Framework 4.8 (или 4.0 Client Profile), Windows PowerShell 5.1+.
* **Права доступа**: Права локального Администратора рекомендуются для разовой системной регистрации надстройки и шрифтов. Основная функциональность надстройки и макросов регистрируется в профиле текущего пользователя (`HKCU`) и работает **без прав администратора**.

### Порядок установки на новое рабочее место (один клик)

1. Склонируйте/скопируйте репозиторий на целевую машину (папка `_Инструменты_Конструктора`, диск любой).
2. **Двойной клик по `УСТАНОВИТЬ_ЕСКД.bat` в корне репозитория** — батник сам запросит права администратора (UAC), закроет SolidWorks и выполнит весь конвейер (при отсутствии DLL надстройки соберёт её из исходников).
3. Ручной эквивалент (консоль PowerShell от имени Администратора):
   ```powershell
   powershell -ExecutionPolicy Bypass -File ".\01_Настройки_SolidWorks\Setup_Workstation_SolidWorks.ps1"
   ```
4. Скрипт выполнит:
   - Импорт корпоративных настроек интерфейса SolidWorks 2025 (`.reg`);
   - Установку чертежных шрифтов ГОСТ тип A и тип B с автоматическим выбором режима: системная установка в каталог Windows Fonts (HKLM, требуется администратор) или пользовательская (HKCU, `%LOCALAPPDATA%\Microsoft\Windows\Fonts`) с уведомлением `WM_FONTCHANGE`;
   - Привязку путей поиска к форматам листов (`.slddrt`), шаблонам (`.prtdot`, `.drwdot`) и библиотеке материалов (`.sldmat`);
   - Регистрацию COM-надстройки **ЕСКД (v5)** в SolidWorks AddIns и автозапуске;
   - Добавление вкладки **«ЕСКД»** в CommandManager для деталей, сборок и чертежей;
   - Закрепление 9 кнопок макросов пакета **SWPlus** в верхней панели быстрого доступа (QAT);
   - Активацию безопасного графического режима (исключающего черный экран в SolidWorks 2025);
   - Интеграцию модуля автоматизации черчения **Drw (Drew)**.
5. Запустите **SolidWorks 2025**. Убедитесь, что на панели CommandManager присутствует вкладка «ЕСКД», а в верхней строке — кнопки SWPlus.

## 🏛️ Архитектура программного комплекса

### 1. Нативная надстройка ESKD Material Sync (C# .NET)
Каталог: `03_Макросы_и_Плагины/ESKD_Material_Sync_Addin/`

* **Назначение**: ядро автоматизации v6. Реквизиты пишутся перед сохранением (`FileSaveNotify`) и после «Сохранить как»; открытие и переключение окон ничего не меняют. Имена свойств — словарь SWPlus, уровни хранения — как у MProp; дробь материала и масса для основной надписи, кнопка «Деталь БЧ».
* **Ключевые модули**:
  - `Core/`: словарь SWPlus, разбор имени файла, разметка граф, библиотека материалов, журнал (без SolidWorks, покрыты юнит-тестами);
  - `Sw/`: `PropertyWriter` — единственная точка записи свойств, `SyncService`, `EventHub`, `BchService`;
  - `SettingsForm.cs`: окно настроек надстройки (фамилия, организация, точность массы);
  - `build.ps1`: сборка DLL и утилит системным `csc.exe` (Visual Studio не нужна) и `build_manifest.json` с хешами;
  - `Register-EskdAddin.ps1`: единственный модуль регистрации — его используют Setup, `register_eskd.ps1`, `build_and_register.ps1`, `unregister.ps1` и конфигуратор.
* **Автономные утилиты**:
  - `ESKD.exe` / `ESKD_Sync.exe`: Консольные и оконные утилиты ручной синхронизации активного документа SolidWorks.

## 📐 Правила и стандарты автоматизации ЕСКД

### 1. Связь штампа чертежа (`$PRPSHEET`) с 3D-моделью
В чертежах SolidWorks по стандарту ГОСТ 2.104 текстовые заметки штампа оформлены через связывающие переменные:
* `$PRPSHEET:"Обозначение"` — децимальный номер изделия;
* `$PRPSHEET:"Наименование"` — наименование детали или узла;
* `$PRPSHEET:"Материал"` / `$PRPSHEET:"Материал_ФБ"` — наименование и сортамент материала;
* `$PRPSHEET:"Разраб."` — фамилия разработчика;
* `$PRPSHEET:"Организация"` — предприятие/фирма.

> [!IMPORTANT]
> Переменные `$PRPSHEET` опрашивают **активную конфигурацию 3D-модели в первичном чертежном виде**, а не сам файл чертежа `.slddrw`. При сохранении чертежа или смене настроек в надстройке ЕСКД реквизиты автоматически прописываются в исходную 3D-модель с перестроением чертежа, гарантируя актуальность штампа.

### 2. Двухэтажные дроби материалов по ГОСТ
Для деталей из сортового и листового проката основная надпись требует записи материала в виде двухэтажной дроби:
$$\frac{\text{Сортамент ГОСТ}}{\text{Марка стали ГОСТ}}$$

Надстройка формирует в свойстве `Материал_ФБ` валидную строку форматирования SolidWorks:
```
<STACK>Труба 80х80х4 ГОСТ 8639-82<OVER>Ст3сп ГОСТ 380-2005</STACK>
```
Чертежный штамп автоматически отображает дробь с горизонтальной линией деления в строгом соответствии с ГОСТ 2.104.

### 3. Защита стандартных и покупных изделий (SProp / Toolbox)
При автосохранении детали надстройка проверяет предикат `IsStandardOrPurchasedPart`:
1. Заполнено ли свойство `Раздел` со значениями: `Стандартные изделия`, `Прочие изделия`, `Материалы`, `ЭМ-`;
2. Имеются ли свойства `IsFastener`, `Наименование_ВП`, `Поставщик`, `Код_Продукции`, `Обозначение_ДНП`;
3. Расположена ли деталь в каталоге библиотеки `Toolbox` (`\toolbox\`, `solidworks data`).

Если деталь признана стандартной, надстройка **пропускает** автоформирование наименования/обозначения из имени файла и сохраняет каталожные данные в исходном виде.

### 4. Безопасное сохранение сборок без рекурсии
При сохранении сборки (`swDocASSEMBLY`) надстройка вызывает изолированный метод `SyncAssembly`. Обрабатываются свойства исключительно самого верхнего уровня сборки (наименование, шифр `СБ`, масса узла). Метод **не выполняет обход компонентов** (`GetComponents()`), предотвращая задержки при сохранении больших проектов.

### 5. Стабилизация координат штампа (Zero-Drift)
Все динамические смещения заметок штампа при сохранении нейтрализованы. Точные координаты аннотаций жестко зафиксированы эталонными форматами листов `.slddrt`. Смещение заметок при `Ctrl+S`:
$$\Delta X = 0.0000 \text{ мм}, \quad \Delta Y = 0.0000 \text{ мм}$$

## ❓ Часто задаваемые вопросы и устранение неполадок (FAQ / Troubleshooting)

### 1. После установки не видна вкладка «ЕСКД» в CommandManager
* **Причина**: SolidWorks при закрытии может перезаписывать ветку реестра CommandManager своим кэшем из оперативной памяти.
* **Решение**:
  1. Закройте SolidWorks.
  2. Запустите скрипт перерегистрации:
     ```powershell
     powershell -ExecutionPolicy Bypass -File ".\03_Макросы_и_Плагины\ESKD_Material_Sync_Addin\register_eskd.ps1"
     ```
  3. Запустите SolidWorks. Если вкладка все еще скрыта, щелкните правой кнопкой мыши по любой вкладке CommandManager и включите галочку напротив **«ЕСКД»**.
  4. Также **Tier 4** при запущенном SolidWorks проверяет надстройку в живой сессии через COM (`GetAddInObject`) — если надстройка загружена, вкладка создаётся программно при каждом старте, и отсутствие записи в реестре не влияет на её наличие в интерфейсе.

### 2. Кнопки макросов SWPlus в верхней панели QAT отображаются серыми значками
* **Причина**: Не совпадает сопоставление ID кнопок меню (`Menu Customizations`) и панели быстрого доступа (`GB0`).
* **Решение**: Запустите `Setup_Workstation_SolidWorks.ps1`. Скрипт принудительно сопоставляет кнопки с системными ID `33639..33647` и очищает кэш изменений тулбаров.

### 3. Черный экран рабочей области в SolidWorks 2025
* **Причина**: Несовместимость видеокарты или драйвера с новым графическим конвейером SolidWorks (*Enhanced Graphics Performance*).
* **Решение**: Скрипт развертывания автоматически отключает данный режим в реестре:
  ```powershell
  Set-ItemProperty -Path "HKCU:\Software\SolidWorks\SOLIDWORKS 2025\Performance" -Name "Use Performance Pipeline 2020" -Value 0
  ```

### 4. Как пересобрать надстройку после изменения исходного кода C#?
Запустите скрипт компиляции:
```powershell
powershell -ExecutionPolicy Bypass -File ".\03_Макросы_и_Плагины\ESKD_Material_Sync_Addin\build_and_register.ps1"
```
Скрипт запускает `build.ps1` (системный `csc.exe` .NET Framework 4: `ESKD_Material_Sync_v5.dll`, `ESKD.exe`, `ESKD_Sync.exe`, `build_manifest.json`) и регистрирует надстройку модулем `Register-EskdAddin.ps1`. Команды выполняются из корня репозитория.
