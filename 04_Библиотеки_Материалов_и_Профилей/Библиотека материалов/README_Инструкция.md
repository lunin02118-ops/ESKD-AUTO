# Инструкция по использованию и подключению библиотеки материалов ГОСТ в SolidWorks

## 1. Подключение библиотеки в SolidWorks

1. Запустите **SolidWorks**.
2. Перейдите в меню: `Инструменты` → `Параметры...` (или значок шестерёнки вверху).
3. В левой панели выберите вкладку **«Настройки пользователя»** → раздел **«Расположение файлов»**.
4. В выпадающем списке «Отобразить папки для:» выберите пункт **«Базы данных материалов»**.
5. Нажмите кнопку **«Добавить»** и укажите сетевой/локальный путь к этой папке:
   `\\home-pc\инструменты_конструктора\04_Библиотеки_Материалов_и_Профилей\Библиотека материалов`
6. Нажмите **«ОК»** для сохранения настроек.

---

## 2. Назначение материала детали

1. В дереве конструирования (FeatureManager) нажмите правой кнопкой мыши на пункт **«Материал»** → **«Редактировать материал»**.
2. В появившемся дереве библиотек раскройте базу **`Библиотека материалов (Сортамент ГОСТ)`**.
3. Выберите нужную категорию:
   - *01. Прокат листовой горячекатаный (ГОСТ 19903-2015)*
   - *02. Трубы стальные профильные квадратные (ГОСТ 8639-82)*
   - *03. Трубы стальные бесшовные горячедеформированные (ГОСТ 8732-78)*
   - *04. Марки сталей и сплавов (Базовые материалы)*
4. Выберите требуемый типоразмер и нажмите **«Применить»**, затем **«Закрыть»**.

---

## 3. Автоматическое отображение в чертежах (ГОСТ Р 2.104-2023)

- В основной надписи чертежа (штампе) в графе 3 («Материал») заметка должна содержать ссылку:
  `$PRPSHEET:"Material"` или `$PRPSHEET:"Материал"`
- При назначении материала из данной библиотеки SolidWorks автоматически отрисует **дробь по ГОСТ** с горизонтальной разделительной чертой:
  - **Числитель:** Сортамент, типоразмер и стандарт сортамента (например, `Лист Б-ПН-НО-4,0 ГОСТ 19903-2015` или `Труба 80х80х4 ГОСТ 8639-82`).
  - **Знаменатель:** Марка стали и стандарт на поставку (например, `Ст3сп ГОСТ 14637-2024` или `В 10 ГОСТ 13663-86`).

---

## 4. Как пополнять базу по ограничительному перечню

1. Откройте файл `Шаблон_Ограничительный_перечень.csv` в Microsoft Excel или любом текстовом редакторе.
2. Добавьте новые строки с необходимыми типоразмерами.
3. Сохраните файл как CSV (с разделителем точка с запятой `;`).
4. Запустите скрипт генератора через командную строку:
   ```cmd
   python generate_materials.py Шаблон_Ограничительный_перечень.csv
   ```
5. Файл `Библиотека материалов (Сортамент ГОСТ).sldmat` обновится автоматически.
