## Как запускать (пользовательская инструкция)

1. Открыть чертёж в SolidWorks.
2. Инструменты → Макрос → Выполнить… → выбрать `.swp`:
   - `Чертежи\Линейные габариты\8.0 Beta WORK вершины.swp` (последняя рабочая ветка габаритов);
   - `Чертежи\Угловые размеры\Углы V32.0 .swp` (финальная углов);
   - `Чертежи\Авторазмер V1.0.swp`;
   - `Чертежи\Прочее\Стиль линий V1.0.swp`.
3. На вопрос макроса ввести **A** (активный лист) или **B** (все листы).
4. Исходники для правок: `D:\dev\macro_restore\…` (после правки импортировать в SW: Инструменты → Макрос → Редактировать, вставить модуль).
