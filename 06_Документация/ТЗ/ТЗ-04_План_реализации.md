## 0. Главные технические решения

| № | Решение | Почему |
|---|---|---|
| Т4-1 | **Строки пишет надстройка, числа считают формулы.** Состав листов (какие детали на каком участке, какие длины в каком сортаменте) не зависит от тиража — его пишет К-4 готовыми строками. Всё, что зависит от тиража и норм (всего шт., хлысты, м, кг, КИМ, краска), — формулы Excel со ссылкой на ячейки «Паспорт!Тираж» и лист «Нормы». | Работает в любой версии Excel (без FILTER/динамических массивов), пересчёт мгновенный, книга читается без надстройки. Состав изделия меняется только вместе с моделью — тогда К-4 и так перезапускается. |
| Т4-2 | **Основа книги — выгрузка SWTools** (лист «Ведомость» с эскизами, как сейчас). Остальные листы добавляет надстройка кодом, как сегодня «Покраска» и «Покупные». Перенос листов между книгами не делаем. | Эскизы вставляет только SWTools; копирование листа с рисунками и стилями между книгами — сложно и хрупко. Шаблон SWTools встроенный (`BuiltIn:BomTemplateLzk`) и живёт в его репозитории. |
| Т4-3 | **Тексты бланков — в справочнике, который правит владелец:** `02_Шаблоны_и_Форматки\Справочники\ЛЗК_бланки.xlsx` — названия участков, операции участка и синонимы, подписанты, заголовки, «Технологические указания» по умолчанию. | Владелец меняет формулировки и подписи без программиста; вёрстку листов держит код. |
| Т4-4 | **PDF — через Excel** (COM, позднее связывание: открыть, пересчитать, `ExportAsFixedFormat` по листам участков). Нет Excel — кнопка объясняет и ничего не пишет. | Формулы в PDF должны быть посчитаны; кроме Excel их никто не посчитает. Excel стоит на рабочих местах КТО. |
| Т4-5 | **Сводная на заказ и окно «Выдать» выводятся из работы** (`IssueForm`, `ProdRequest`, `ProdRequestBook`, копирование в `_Производство`). `Norms` и `CutPlan` остаются: нормы копируются в лист «Нормы», `CutPlan` — для «оптимального» справочного числа хлыстов. | Р4-6, Р4-8. |

## 1. Книга `ЛЗК_<шифр>.xlsx`

Путь: `<изделие>\04_Сопроводительная документация\ЛЗК_<шифр>.xlsx`; прежняя — `<изделие>\_Аннулировано\ЛЗК_<шифр>_<дата>_<время>.xlsx`;
отчёт — `<изделие>\_Ведомость.txt` (как сейчас). Все листы — А4, области печати, повтор шапки таблицы.

### 1.1 «Паспорт» (первый лист)
| Ячейка (имя) | Содержимое | Источник |
|---|---|---|
| `Изделие`, `Шифр`, `Сборка`, `КонтрСумма`, `Составил`, `Дата` | как шапка сейчас | К-4 |
| `Заказ`, `НомерСЗ` | из имени папки заказа / ввод | К-4, правится |
| **`Тираж`** | Изделий в заказе (жёлтая ячейка ввода, проверка «целое ≥ 1») | окно К-4, правится в Excel |
| **`Срок`** | Срок отгрузки (дата) | окно К-4, правится |
| `Цвет` | RAL | окно К-4, правится |
| `Выдано` | дата/кто — пишет «Готово к производству» | К-5 |

### 1.2 «Ведомость» (подетальная, на 1 шт.) — лист SWTools + колонки надстройки
Колонки SWTools A–J без изменений (№, Эскиз, Обозначение, Наименование, Материал, Габарит, Масса, Кол-во, Операции, Путь).
Надстройка дописывает справа: **K «Категория»** (Сборка / Деталь / Покупное / Прочее / Материал — по «Разделу»),
**L «Участки»** (по справочнику), **M «Всего на тираж»** `=H7*Тираж`. Фильтр/сортировка — автофильтр на строке заголовков
(или «таблица Excel», если проверка этапа 0 покажет, что эскизы с ней не путаются). Итог массы — формула.

### 1.3 Листы участков: «Заготовительный», «Сварочный», «Покрасочный», «Комплектовочный»
Шапка: изделие, шифр, **тираж**, **срок отгрузки**, цвет (для покрасочного), дата выдачи. Таблица — строки, у которых
есть операция участка (Т4-1): № / Обозначение / Наименование / Материал / L или габарит / На 1 / **Всего `=На1*Тираж`** / Операция.
Комплектовочный: механическая сборка + покупные (код 1С, ед., ОКЕИ, на 1, всего). Покрасочный: площадь 1 шт., всего м², цвет.
Внизу — «Технологические указания» (текст из справочника, правится в книге и **сохраняется при перестроении**) и подписи
Нач. КТО и начальника участка (из справочника).

### 1.4 «Расход» — калькулятор
Строки пишет надстройка — **по одной на каждую длину заготовки каждого сортамента** трубы/проката; формулы:

| Колонка | Формула (пример строки 5) |
|---|---|
| Сортамент, L мм, На 1 шт. | значения |
| Всего шт. | `=C5*Тираж` |
| В хлыст | `=ЕСЛИ(B5>0;ОТБР((Хлыст-Захват-Торцовка)/(B5+Рез));0)` |
| Хлыстов | `=ЕСЛИ(E5>0;ОКРУГЛВВЕРХ(D5/E5;0);"?")` |
| Чистые м | `=D5*B5/1000` |
| С потерями, м | `=F5*Хлыст/1000` |
| КИМ | `=ЕСЛИОШИБКА(G5/H5;"")` |
| Деловой остаток, мм | `=Хлыст-Захват-Торцовка-E5*(B5+Рез)` (≥ «Деловой» — «да») |
| Масса, кг | `=H5*МассаПогМ` (масса пог. м — из модели: масса детали / L) |

Итоги по сортаменту — `СУММЕСЛИ`. Ниже: **листы** (`=ОКРУГЛВВЕРХ(Площадь*Тираж*ЛистОтход/ПлощадьЛиста)`), **краска**
(`=ПлощадьПокраски*Тираж*КраскаНорма/1000*(1+КраскаПотери/100)`, тара — `ОКРУГЛВВЕРХ`), **покупные итого**.
Справочно — «оптимальная раскладка» `CutPlan` на введённый в окне тираж (число, с пометкой «на тираж N»).

### 1.5 «Нормы»
Копия `Нормативы_производства.xlsx` на момент первого формирования (ключи Труба.Хлыст=6000, Захват, Торцовка, Рез, Деловой,
Лист.Формат, Лист.Отход, Краска.Норма, Потери, Тара) с именованными ячейками. Правится под заказ; **при перестроении
сохраняется**. Нет файла нормативов — лист со значениями по умолчанию ТЗ-02 Т-13 и замечание «?».

## 3. Этапы

### Этап 0. Проверки-«шипы» (0,5–1 дня) — до основной работы
1. Формула, записанная `XlsxBook` без кэша, + `fullCalcOnLoad` — Excel открывает и считает; `XlsxBook.Get` у такой ячейки даёт пусто (учесть в чтении).
2. Автофильтр на листе SWTools: сортировка по «Категории» — **эскизы остаются у своих строк?** Если нет — проверить привязку рисунков SWTools («перемещать и изменять размер с ячейками») и «таблицу Excel»; решение записать.
3. Excel COM: открыть книгу, пересчитать, PDF одного листа; время на 4 листа.
4. Именованные ячейки в формулах на русском Excel (`ОКРУГЛВВЕРХ` в файле хранится как `ROUNDUP` — писать английские имена функций).
**Выход:** короткая записка с результатами; при провале п. 2 — «Категория» и сортировка только на отдельном листе без эскизов.

### Этап 1. Живая книга (3–4 дня)
1. `Xlsx.cs`: формулы, пересчёт, имена, автофильтр, проверка ввода, ориентация. Юнит-тесты на каждую возможность (чтение XML книги).
2. `LzkSections.cs`, `LzkBook.cs`: «Паспорт», K–M «Ведомости», «Расход», «Нормы». Юнит-тесты: группировка по сортаменту/длине, формулы строк, имена.
3. `LzkService`: новый путь, окно с тиражом/сроком/цветом, длина заготовки/масса пог. м, сохранение ввода, миграция старой ведомости.
4. Длина заготовки трубы у модели-тела: наибольший габарит, пометка «*» и замечание (см. вопрос В-1).
5. **Приёмка:** на копии NC3-7R в `D:\Work\_dev\_lzk_боевой`: тираж 1, 41, 100 — ввод в «Паспорт» пересчитывает «Всего», хлысты, м, кг, краску; ручная проверка хлыстов по формуле раскроя «пакетом» (сверка с правилом сводной 85_Т); повторный К-4 сохраняет тираж/срок/цвет/нормы; e2e `test_e2e_lzk.py` L01–L03 обновлены (новый путь и листы) + новые L04 (формулы и имена), L05 (сохранение ввода).

### Этап 3. Документы, права, развёртывание (1–1,5 дня)
