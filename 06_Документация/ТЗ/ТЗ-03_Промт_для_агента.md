Как определить изделие (от сильного к слабому):
 1) уже есть папка изделия/позиции ("СУAt-05 Стол учителя", позиции 700 "N.NN_…", "641-1 Островной");
 2) корневая сборка (.a3d/.sldasm) + все файлы, на которые она ссылается (через MCP) + их чертежи;
 3) общий префикс обозначения (85T.СМ.*, 61-1.05.01.*, ПА.00.*, СУAt-05.*);
 4) общее наименование в имени файла;
 5) иначе — 02_Металл\И00_Не разобрано\ (с той же раскладкой по типам) + отчёт.
 ИМЯ ПАПКИ ИЗДЕЛИЯ = И<nn>_<шифр>_<наименование>:
   - И<nn> = НОМЕР ПОЗИЦИИ В СЛУЖЕБНОЙ ЗАПИСКЕ (поз. 1 → И01). Нет СЗ / позиция не найдена — следующий свободный номер + вопрос.
   - шифр = обозначение главной сборки без нулевых хвостов (.00.00.000 / .00.000 / .000):
     85T.СМ.00.000 → 85T.СМ;  СУAt-05.00.000 → СУAt-05;  61-1.05.01.000 → 61-1.05.01;  ТС-85.00.00.000 → ТС-85.
     Писать ТОЧНО как в именах файлов (латиницу/кириллицу не исправлять; смешение — в отчёт). Нет шифра — поле опустить.
   - наименование — из СЗ, коротко. Для 700 без шифра — номер позиции: И<nn>_<N.NN>_<наименование>.
   - всё имя ≤ 40 символов (сокращать наименование, не шифр).
   Пример: «И01_85T.СМ_Кровать одноместная» (было неверно: «И01_85T Кровать»).
 Сборку с её моделями и чертежами класть в 01_3D одного изделия ЦЕЛИКОМ, подпапки относительно сборки сохранять.

Версии: одинаковое имя, разное содержимое → актуален файл из 04_Готово, при равенстве этапов — более новый;
вытесненный → _Аннулировано. Одинаковый SHA-256 в нескольких местах → один экземпляр, остальные → _Аннулировано\_дубли.
