## 2. Книга «ЛЗК изделия»

Строится кнопкой К-4 «Ведомость ЛЗК» по **шаблону** `02_Шаблоны_и_Форматки\Шаблоны документов\ЛЗК_изделия.xlsx`
(обычный файл Excel с формулами; внешний вид и тексты владелец правит сам). Надстройка заполняет только
данные и «Паспорт»; всё остальное считают формулы шаблона. Файл открывается с пересчётом (fullCalcOnLoad).

| Лист | Содержимое | Заполняет |
|---|---|---|
| **Паспорт** | Изделие, шифр, заказ, № СЗ, **Изделий в заказе** (ввод), **Срок отгрузки** (ввод), цвет RAL, Нач. КТО, дата, контрольная сумма сборки | надстройка — значения по умолчанию из окна К-4; конструктор правит в Excel |
| **Ведомость** (подетальная, на 1 шт.) | таблица Excel с фильтрами: №, Эскиз, **Категория**, Обозначение (с исполнением), Наименование, Материал, Длина заготовки / габарит, Масса, На 1 шт., **Всего = На 1 × Тираж**, Операции, **Участки** | данные — надстройка, «Всего» и «Участки» — формулы |
| **Заготовительный / Сварочный / Покрасочный / Комплектовочный** | строки своего участка, шапка (изделие, тираж, срок, цвет), колонки «на 1 / всего», подписи Нач. КТО и начальника участка, блок «Технологические указания» | формулы отбора из «Ведомости» |
| **Расход** | по сортаменту: Σ длин × тираж, штук в хлыст, хлыстов, м и кг с потерями, КИМ, деловой остаток; листы; краска кг и тара; покупные итого | формулы |
| **Нормы** | копия нормативов на момент формирования, правится под заказ | надстройка копирует, конструктор правит |
| **Справочник** (скрыт) | операция → участок, синонимы, категории | шаблон |

**Категория** — по свойству «Раздел»: Сборочные единицы → Сборка; Детали → Деталь; Стандартные/Покупные изделия →
Покупное; Прочие изделия → Прочее; Материалы → Материал. Нет свойства — по признакам (сборка/деталь, покупная папка).

**Хлысты (формула):** по каждой длине заготовки `в_хлыст = ОТБР((Хлыст − Захват − 2·Торцовка)/(L + Рез))`,
`хлыстов = ОКРУГЛВВЕРХ(всего_шт / в_хлыст)`; по сортаменту — сумма. Хлыст 6000 мм.

**Эскизы:** привязаны к ячейке («перемещать и изменять размер вместе с ячейками») — сортировка таблицы их не путает.
Перед сохранением моделей в К-4 скрываются эскизы, плоскости, оси, начало координат, точки, примечания; вид —
изометрия, «показать всё» — превью в файлах чистые.

**Длина заготовки трубы** — из списка вырезов (LENGTH) или RD1; иначе для модели-тела из трубы — наибольший
габарит с пометкой «*» и замечанием «?» (калькулятор хлыстов без длины неточен).

## 3. Кнопки

* **К-4 «Ведомость ЛЗК»:** окно «Операции» (с эскизами) + поля «Изделий в заказе», «Срок отгрузки», «Цвет» (подставляются
  прошлые значения) → свойства моделей → SWTools (данные и эскизы) → книга по шаблону в `04_Сопроводительная документация`.
  Повторный запуск сохраняет введённые в «Паспорте» тираж, срок, цвет, правки «Норм» и «Технологические указания».
* **К-5 «Выдать» → «Зафиксировать выдачу»:** проверка (К-3 = ГОТОВО, нет «?»), PDF книги по участкам в `02_PDF`
  (`ЛЗК_<шифр>_<участок>.pdf`), запись `_Выдано_<дата>.txt` в папку изделия. **Копирования в производство нет.**
* **К-6 «Закрыть заказ»:** без изменений (опирается на `_Выдано_*.txt`).

## 4. Этапы и приёмка

**Этап 1 — живая книга.**
1. Запись Excel: пересчёт при открытии, формулы в данных не пишутся (формулы — в шаблоне), альбомная ориентация.
2. Шаблон `ЛЗК_изделия.xlsx`: Паспорт, Ведомость (таблица, категория, «всего»), Расход, Нормы, Справочник.
3. К-4: книга в `04_Сопроводительная документация`, архив в `_Аннулировано`, окно с тиражом и сроком, сохранение ввода при повторе.
4. Приёмка: на копии 85_Т тираж 41 — хлысты, КИМ и краска совпадают со сводной 85_Т (±1 хлыст на сортамент);
   тиражи 1 и 100 пересчитываются вводом в «Паспорт»; сортировка таблицы не путает эскизы.

**Этап 2 — расцеховка.**
1. Листы участков с отбором по справочнику, шапки, подписи, области печати А4.
2. К-5 «Зафиксировать выдачу»: PDF по участкам, `_Выдано`, без папки производства.
3. Чистые превью при сохранении моделей в К-4.
4. Приёмка: e2e на изделии с деталями всех четырёх участков; PDF — по странице на участок.

**Этап 3 — документы и права.**
Регламент, ТЗ-02/03, руководство, памятки, инструкция «Папка заказа», задание сисадмину (чтение PDF для цеха),
скилл kto-folders — убрать «Производство» (≈15 мест, список — в аудите, раздел 1 п. 5).
