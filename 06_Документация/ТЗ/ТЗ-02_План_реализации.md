**Принимается по умолчанию, если заказчик не возразит:**

1. **Нормативы по станкам** — в справочнике лист «Оборудование»: строка на станок (лазерный труборез, лазер листовой) со своими хлыстом/форматом, захватом, торцовкой, резом, деловым остатком; в листе «Операции» столбец «Станок». Новый станок — новая строка без правки программы. Длина хлыста для отдельного сортамента (например, 12 м) — лист «Сортамент», только нужные строки.
2. **Листовой лазер** — примерные значения (отступ от края 10 мм, рез 0,3 мм, деловой остаток от 0,25 листа), заказчик правит сам.

4. **Раскрой листа** — по площади деталей × коэффициент отхода; точная раскладка остаётся за программой лазера.

## 5. Э2. «Операции» и «СЗ на производство»

**Цель:** конструктор из готовой сборки получает заявку в цех одной кнопкой.

### 5.1. Кнопка «Операции» (`Sw/OperationsService.cs`, `OperationsForm.cs`)

1. Доступна в детали и сборке; в сборке — для выделенных компонентов (можно несколько сразу).
2. Автоподсказка по модели (спайк С-5):
   - есть элемент `SheetMetal` → «Лазерная резка листа»; есть сгибы → «Гибка»;
   - есть `WeldMemberFeat` или тело трубы из профиля → «Лазерная резка трубы»;
   - сборка со сварными швами или сварная конструкция → «Сварная сборка», иначе «Механическая сборка»;
   - заполнено `Покрытие` → «Покраска» (на сварной сборке, не на её деталях).
3. Окно: галочки из листа «Операции» справочника, порядок стрелками, отметка «(авто)» у подсказанных; «Записать» пишет свойство `Операции` через `PropertyWriter` («Лазерная резка трубы; Гибка»).
4. Имя `Операции` — не из словаря SWPlus (слотов нет): вводится константой в `PropertyDictionary` как собственное свойство надстройки; тест S02 расширяется, чтобы литерал был только там.
5. COM-метод `SetOperationsSilent` для тестов.

### 5.2. Кнопка «СЗ на производство» (`Sw/ProdNoteService.cs`, `ProdNoteForm.cs`)

**Расцеховка — только по свойству `Операции`, не по геометрии.** Кнопка обходит дерево сборки и кладёт каждый узел и каждую деталь в лист того цеха, чья операция у неё записана. Автоподсказка по модели работает только в окне кнопки «Операции»; если свойство не заполнено, СЗ ставит подсказку с пометкой «(авто)» и выдаёт замечание.

| Операция в свойстве `Операции` | Лист СЗ | Что попадает в строку |
| :--- | :--- | :--- |
| «Лазерная резка листа», «Лазерная резка трубы», «Гибка» | 1 Заготовка | деталь: обозначение, наименование, сортамент (`SORTAMENT` списка вырезов или `Материал_Строка`), L (`LENGTH` или габарит развёртки), кол-во на изделие с учётом вложенности, операции через «; ». Многотельная деталь — по строкам списка вырезов |
| «Сварная сборка», «Механическая сборка» | 2 Сварка | сборочная единица: обозначение, наименование, операция, масса 1 шт, кол-во. Вложенные сварные узлы — отдельными строками, раньше узла, в который входят |
| «Покраска» | 3 Покраска | окрашиваемая единица целиком — обычно та же сварная сборка, что на листе 2 (как «Лежак» и «Спинка» в 85_Т): обозначение, наименование, кол-во, RAL и поверхность из `Покрытие`, площадь окраски (`SurfaceArea` всех тел единицы) |
| покупное изделие (признаки SProp) | 4 Комплектация | наименование, код 1С из справочника, единица ОКЕИ, кол-во, назначение — обозначение узла, в который входит |
| — | 5 Списание | расчёт: трубы — раскрой по станку операции; лист — площадь развёрток × коэффициент → кг; краска — площадь с листа 3 × норма × потери, до тары |

**Правила обхода:**

1. **Сварка и покраска идут параллельно по одним узлам.** Сварная сборка с операциями «Сварная сборка; Покраска» попадает и на лист 2, и на лист 3 одной и той же строкой — цех сварки её варит, малярный участок красит её же.
2. **Покраска берётся на верхнем отмеченном уровне.** Детали и подузлы внутри окрашиваемой единицы на лист 3 не выводятся и в площадь не складываются второй раз. Если внутри окрашиваемой сборки у детали тоже стоит «Покраска» — замечание «окраска задана дважды».
3. **Детали внутри сварной сборки** идут на лист 1 как заготовки (резка/гибка), а сама сборка — на лист 2. Отдельно окрашиваемая деталь вне сварных узлов — на лист 3 как деталь.
4. **Механическая сборка** (узлы на крепеже) — на лист 2 с операцией «Механическая сборка»; покупной крепёж и фурнитура — на лист 4 с назначением этого узла.
5. **Замечания:** «Покраска» без `Покрытие`; `Покрытие` без «Покраска»; сборка без операции сварки или сборки; деталь без операций заготовки; деталь длиннее хлыста.

**Окно перед записью:**

- реквизиты: дата, № заявки, нач. КТО, изделие, шифр, тираж (по умолчанию 1);
- таблица нормативов станков из справочника: правка действует только на эту заявку, изменённые значения подсвечены, кнопка «Сбросить к справочнику»;
- предварительный итог: хлысты и КИМ по каждой трубе пересчитываются сразу;
- список замечаний: нет операций, нет сортамента, нет длины, деталь длиннее хлыста;
- «Сформировать» пишет `СЗ_<Обозначение>.xlsx` в папку изделия по бланку.

**Запись:**

- бланк `02_Шаблоны_и_Форматки\Шаблоны документов\СЗ_на_производство.xlsx`; строки вставляются, ИТОГО пересчитываются формулами;
- на лист «Данные» пишутся применённые нормативы;
- «Технологические указания» каждого листа, изменённые вручную, при перезаписи сохраняются (Т-13);
- защита листов и книги паролем из настроек;
- отчёт на экране и `_СЗ_<дата>.txt`.

## 12. Риски

| Риск | Что делаем |
| :--- | :--- |
| Длина гнутой трубы: список вырезов даёт длину по осевой без учёта гибки | в СЗ длина со звёздочкой и указание «уточнить по первому образцу», как в 85_Т; позже — припуск на гиб в справочнике |
| Покраска задана и на узле, и на его деталях — площадь посчитается дважды | окраска берётся на верхнем отмеченном уровне, повтор ниже — замечание |
| Конструктор не заполнил операции | СЗ формируется с «(авто)», «Проверить изделие» даёт замечание |
| Бланк СЗ правится вручную и ломает вставку строк | кнопка находит таблицы по заголовкам; при несовпадении — понятная ошибка, а не порча файла |
| Excel-файл справочника открыт при чтении | чтение без блокировки; при ошибке — повтор и сообщение |
| Раскрой по «первому подходящему» не оптимален на смешанных длинах | для заявки достаточно (разница обычно ≤ 1 хлыста); точная раскладка — в программе трубореза |
| Словарь без запасных слотов | новые свойства (`Операции` и дальше) — собственные свойства надстройки, не SWPlus |
