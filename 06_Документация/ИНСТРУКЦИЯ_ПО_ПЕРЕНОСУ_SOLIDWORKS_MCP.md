# 📘 Руководство по установке, переносу и использованию SolidWorks MCP Server

> [!CAUTION]
> **Исторический документ**, написан до версии 6 надстройки ЕСКД. Устарело: MCP-сервер больше не пишет реквизиты и дробь материала сам — он загружает надстройку ЕСКД и делегирует запись ей (дефект Д-20); сетевые пути `\\home-pc\…` относятся к прежней установке.

Данная инструкция описывает процесс развертывания программного моста **SolidWorks MCP (Model Context Protocol)** на любом рабочем компьютере конструктора для прямого управления **SolidWorks** через ИИ-ассистентов (**Antigravity, Claude Desktop, Cursor, Claude Code**).

---

## 1. Что умеет SolidWorks MCP Server

- 🚀 **Прямое управление SolidWorks через чат:** построение 3D-моделей (бобышки, вырезы, скругления, фаски, отверстия).
- 📦 **Интеграция с корпоративной базой ГОСТ:** автоматическое назначение материалов из `Библиотека материалов (Сортамент ГОСТ).sldmat`.
- 📐 **Автоматизация штампа чертежа:** генерация математической дроби ГОСТ `<STACK size=1>Сортамент<OVER>Марка стали</STACK>` в свойство `Материал`.
- 📊 **Расчет характеристик:** точный съем массы (кг), объема ($м^3$), площади поверхности и центра тяжести.
- 💾 **Управление файлами и экспорт:** сохранение `.SLDPRT`, экспорт в `.STEP`, `.DXF`, `.PDF`, `.STL`.

## 2. Системные требования к новому ПК

1. **ОС:** Windows 10 / Windows 11 (x64).
2. **CAD:** Установленный SolidWorks (2021, 2022, 2023, 2024, 2025 или 2026).
3. **Python:** Версия 3.10 или выше ([скачать с python.org](https://www.python.org/downloads/)).  
   *(При установке Python обязательно поставьте галочку **"Add Python to PATH"**)*.
4. **Доступ к локальной сети** к серверу `\\home-pc` (где хранятся шаблоны и библиотека материалов).

## 3. Пошаговый перенос на новый ПК

### Шаг 1. Перенос файлов сервера
Скопируйте папку с MCP-сервером:
```
d:\Development\Projects\Engineering\SolidWorks\github_mcp\alisamsam-solidworks-mcp
```
на новый компьютер в любую удобную директорию, например:
```
C:\Tools\SolidWorks-MCP
```

---

### Шаг 2. Установка зависимостей (1 команда)
Откройте **PowerShell** или **Командную строку** на новом ПК и выполните команду:

```powershell
pip install mcp python-dotenv pywin32
```

---

### Шаг 3. Настройка корпоративных шаблонов (`config.json`)
Откройте файл `C:\Tools\SolidWorks-MCP\solidworks_mcp\config.json` в Блокноте и убедитесь, что в нем прописаны пути к общим сетевым шаблонам:

```json
{
  "exe_path": "auto",
  "part_template": "\\\\home-pc\\инструменты_конструктора\\02_Шаблоны_и_Форматки\\Шаблоны документов\\Деталь.prtdot",
  "assembly_template": "\\\\home-pc\\инструменты_конструктора\\02_Шаблоны_и_Форматки\\Шаблоны документов\\Сборка.asmdot",
  "drawing_template": "\\\\home-pc\\инструменты_конструктора\\02_Шаблоны_и_Форматки\\Шаблоны документов\\Чертеж.drwdot",
  "startup_timeout": 120,
  "default_unit": "mm",
  "log_level": "INFO",
  "log_file": "solidworks_mcp.log"
}
```

---

### Шаг 4. Регистрация сервера в конфигураторе ИИ

#### Вариант А: Для Antigravity / Gemini
Откройте файл конфигурации:
`C:\Users\<Ваше_Имя_Пользователя>\.gemini\config\mcp_config.json`

Добавьте блок `"solidworks"` в список `"mcpServers"`:
```json
{
  "mcpServers": {
    "solidworks": {
      "command": "python",
      "args": [
        "C:\\Tools\\SolidWorks-MCP\\solidworks_mcp_server.py"
      ]
    }
  }
}
```

#### Вариант Б: Для Claude Desktop
Откройте файл:
`%APPDATA%\Claude\claude_desktop_config.json`

Вставьте аналогичную конфигурацию:
```json
{
  "mcpServers": {
    "solidworks": {
      "command": "python",
      "args": [
        "C:\\Tools\\SolidWorks-MCP\\solidworks_mcp_server.py"
      ]
    }
  }
}
```

## 4. Быстрая проверка работоспособности (Smoke Test)

Создайте на новом ПК файл `test_check.py` в папке `C:\Tools\SolidWorks-MCP\` и запустите его:

```python
import win32com.client

print("Подключение к SolidWorks...")
try:
    swApp = win32com.client.GetActiveObject("SldWorks.Application")
    print(f"✅ Успешно! Версия SolidWorks: {swApp.RevisionNumber}")
except Exception as e:
    print("SolidWorks не запущен или ошибка COM:", e)
```

Запуск:
```powershell
python test_check.py
```

## 6. Устранение возможных неполадок (Troubleshooting)

### 1. Ошибка `SolidWorks is not running` / `Cannot connect to COM`
- **Причина:** SolidWorks не запущен или завис предыдущий фоновый процесс `SLDWORKS.exe`.
- **Решение:** Запустите SolidWorks вручную или снимите зависшие процессы через PowerShell:
  ```powershell
  Stop-Process -Name "SLDWORKS" -Force -ErrorAction SilentlyContinue
  ```

### 2. Ошибка `Template not found`
- **Причина:** Недоступен сетевой путь `\\home-pc\...` или файл шаблона перемещен.
- **Решение:** Откройте `config.json` и укажите актуальный локальный или сетевой путь к файлу `Деталь.prtdot`.

### 3. Ошибка `ImportError: No module named win32com`
- **Причина:** Не установлена библиотека `pywin32`.
- **Решение:** Выполните в консоли:
  ```powershell
  pip install pywin32
  ```
