## 1. Введение и цели модернизации

В ходе генерального аудита и наведения порядка в рабочей среде конструктора (`d:\Work\_Инструменты_Конструктора`) был выполнен комплексный анализ используемых шаблонов документов, форматок чертежей и пакета макросов **SWPlus v2018 SP0.0** (автор *Leon*, сообщество *cccp3d.ru*) под управлением **SolidWorks 2025 SP3.0**.

### Ключевые цели:
1. Выявить и устранить скрытые дефекты в базовых шаблонах документов SolidWorks.
2. Разработать эталонные, независимые шаблоны по ГОСТ ЕСКД (`Деталь ГОСТ.prtdot`, `Сборка ГОСТ.asmdot`, `Чертеж ГОСТ.drwdot`), сохранив оригинальные для обратной совместимости.
3. Обеспечить 100% бесшовную двустороннюю интеграцию со связкой макросов **SWPlus** (`MProp`, `Master`, `SpecEditor`), форматами `.slddrt` и сетевой библиотекой материалов (`Библиотека материалов (Сортамент ГОСТ).sldmat`).
4. Провести сквозное тестирование через SolidWorks API / MCP: моделирование -> назначение ГОСТ сортамента -> автозаполнение штампа -> экспорт в STEP/PDF.

## 3. Архитектура созданных эталонных шаблонов ГОСТ ЕСКД

Шаблоны размещены в каталоге:  
`02_Шаблоны_и_Форматки\Шаблоны документов\`

### 3.1. `Деталь ГОСТ.prtdot`
* **Оформление:** Загружен единый корпоративный стандарт `MyStandard.sldstd` (SWPlus ГОСТ, GOST ID: 5).
* **Единицы измерения:** MMGS (миллиметр, грамм, секунда, угол — градусы, 2 знака).
* **Очистка:** Удалены все рудиментарные конфигурационные свойства.
* **Предустановленная матрица свойств (22 свойства):**
  * *Стандартные ЕСКД:* `Обозначение`, `Наименование`, `Материал` (`"SW-Material"`), `Масса` (`"SW-Mass"`), `Разраб.` (`Петров`), `Организация` (`ООО "Фирма 2"`), `Литера`, `Формат` (`А4`), `Перв_Примен`.
  * *Интеграционные для SWPlus / Formats:* `Наименование_ФБ`, `Материал_ФБ` (`"SW-Material"`), `Материал_Таблица` (`"SW-Material"`), `Масса_ФБ` (`"SW-Mass"`), `Литера_ФБ`, `Контора` (`ООО "Фирма 2"`), `Конструктор` (`Петров`), `Проверил`, `Техконтроль`, `Нормоконтроль`, `Утвердил`, `Сборка1_ФБ`, `Сборка2_ФБ`.

### 3.2. `Сборка ГОСТ.asmdot`
* **Оформление:** Загружен `MyStandard.sldstd` (SWPlus ГОСТ, GOST ID: 5).
* **Очистка:** Вычищены 30 старых полей с префиксами `п_`.
* **Свойства (General):** Включают `Обозначение`, `Наименование`, `Масса`, `Разраб.`, `Организация`, `Литера`, `Перв_Примен`, а также парные поля SWPlus (`Наименование_ФБ`, `Масса_ФБ`, `Контора`, `Конструктор`, `Литера_ФБ`, `Сборка1_ФБ` = `"СБ"`).

### 3.3. `Чертеж ГОСТ.drwdot`
* **Формат листа:** А3 альбомный (420 x 297 мм), масштаб 1:1, метод проецирования — Первый угол (First Angle / Европейский / ЕСКД).
* **Основная надпись:** Динамически привязана к внешней форматке `03_Макросы_и_Плагины\Макросы_SW_ZTool\SWPlusMacro_v_2018_SP0.0\Основные надписи\A3-A-1.slddrt`.
* **Очистка:** Удалены все устаревшие жестко прописанные авторы (Admin) и даты.
* **Имя листа:** `Лист1` (соответствует алгоритму макроса `Master`).

## 6. Рекомендации для конструктора при повседневной работе

1. **Создание новой детали:**
   * Выбирать шаблон `Деталь ГОСТ` (`Деталь ГОСТ.prtdot`).
   * В дереве конструирования правой кнопкой нажать *«Материал»* -> выбрать сортамент из папки *«Библиотека материалов (Сортамент ГОСТ)»*.
   * Открыть макрос `MProp` -> ввести обозначение и наименование -> нажать *«Применить»*.
2. **Создание чертежа:**
   * Нажать *«Файл» -> «Создать чертеж из детали»* -> выбрать шаблон `Чертеж ГОСТ`.
   * Перетащить главный вид на поле чертежа.
   * Штамп (обозначение, наименование, дробь материала, масса, масштаб, организация, фамилия) **заполнится мгновенно без ручного ввода**.
   * При необходимости сменить формат листа (например, с А3 на А2 или А4) — запустить макрос `Master` и выбрать желаемый формат.
3. **Формирование спецификации:**
   * В сборочной единице запустить `SpecEditor` -> нажать кнопку создания спецификации. Все данные из свойств деталей считаются автоматически.
