## 1. Цель и методика тестирования
Проведено автоматизированное сквозное тестирование через **SolidWorks MCP** и API SolidWorks 2025:
1. Создание 3D-детали (пластина $120 \times 80 \times 3$ мм) из корпоративного шаблона `Деталь.prtdot`.
2. Назначение физического материала из сетевой базы:
   `\\home-pc\инструменты_конструктора\04_Библиотеки_Материалов_и_Профилей\Библиотека материалов\Библиотека материалов (Сортамент ГОСТ).sldmat`.
   * Выбран материал: **«Лист 3,0 ГОСТ 19903-2015 / Ст3сп ГОСТ 14637-89»**.
3. Запись ЕСКД-свойств по правилам макроса `MProp`:
   * Свойство `Материал_ФБ` (Графа 3 штампа):  
     `<STACK size=1>Лист Б-ПН-3,0 ГОСТ 19903-2015<OVER>Ст3сп ГОСТ 14637-89</STACK>`
   * Свойство `Материал_Таблица` (Спецификация):  
     `Лист 3,0 ГОСТ 19903-2015 / Ст3сп ГОСТ 14637-89`
   * Обозначение: `ПРТИ.468211.001`, Наименование: `Планка опорная`.
4. Создание чертежа из корпоративного шаблона `Чертеж.drwdot` (Формат А3, ГОСТ 2.104 Форма 1).
5. Размещение проекционного вида детали и захват рендеров в высоком разрешении.

## 3. Выводы
1. **Тег `<STACK size=1>...<OVER>...</STACK>`:**  
   Графическое ядро SolidWorks 2025 на 100% поддерживает этот синтаксис и автоматически рендерит его как дробь с горизонтальной разделительной линией.
2. **Библиотека материалов:**  
   Поле `<description>` в `Библиотека материалов (Сортамент ГОСТ).sldmat` передается в штамп чертежа без искажений и сбоев кодировки.
3. **Совместимость с MProp:**  
   Формат данных полностью согласован со структурой `MProp.swp` и файлом сопоставления полей `MyProperties_1.ini`.
