# Технические требования на чертежах по ГОСТ 2.316-2008 / ЕСКД
## Руководство конструктора и база типовых шаблонов макроса ТТ (SWPlus)

---

## 1. Назначение и нормативная база

Технические требования (ТТ) являются неотъемлемой частью рабочего чертежа детали или сборочной единицы и регламентируют требования к изготовлению, контролю, приемке, транспортированию и монтажу изделия, которые не могут быть выражены графически.

### Основные стандарты ЕСКД:
- **ГОСТ 2.316-2008** — «ЕСКД. Правила нанесения надписей, технических требований и таблиц на графических документах».
- **ГОСТ 2.104-2006** — «ЕСКД. Основные надписи».
- **ГОСТ 30893.1-2002 (ИСО 2768-1)** — «Общие допуски. Предельные отклонения линейных и угловых размеров без индивидуально указанных допусков».
- **ГОСТ 30893.2-2002 (ИСО 2768-2)** — «Общие допуски. Допуски формы и расположения поверхностей без индивидуально указанных допусков».
- **ГОСТ 14771-76** — «Дуговая сварка в защитном газе. Соединения сварные. Основные типы, конструктивные элементы и размеры».
- **ГОСТ 23518-79** — «Дуговая сварка в защитных газах. Соединения сварные под острыми и тупыми углами».
- **ГОСТ ИСО 9013-2017** — «Резка тепловая. Классификация резов, полученных кислородной, плазменной и лазерной резкой. Геометрические характеристики и допуски».
- **ГОСТ Р ИСО 13920-2017** — «Сварка. Общие допуски на сварные конструкции. Линейные и угловые размеры. Форма и положение».
- **ГОСТ Р ИСО 17637-2014** — «Неразрушающий контроль сварных соединений. Визуальный контроль».
- **ГОСТ Р ИСО 5817-2021** — «Сварка. Сварные соединения из стали, никеля, титана и их сплавов... Уровни качества по дефектам».

## 2. Правила размещения и оформления ТТ по ГОСТ 2.316-2008

```
+-------------------------------------------------------------+
| Лист чертежа (А4, А3, А2, А1, А0)                           |
|                                                             |
|                       [Виды изделия]                        |
|                                                             |
|                                                             |
|                         [ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ]            |
|                         Ширина колонки: 185 мм              |
|                         Отступ над штампом: 5...10 мм       |
|                         1. *Размеры для справок.            |
|                         2. Общие допуски: ГОСТ 30893.1-m... |
|                         3. ...                              |
|                         +-----------------------------------+
|                         | ОСНОВНАЯ НАДПИСЬ (ШТАМП ГОСТ)     |
|                         | Ширина: 185 мм, Высота: 55 мм     |
+-------------------------+-----------------------------------+
```

1. **Координаты и геометрия размещения:**
   - Технические требования размещаются **над основной надписью (штампом)**.
   - Ширина колонки текста ТТ **строго равна ширине штампа — 185 мм**.
   - Нижняя строка ТТ должна отстоять от верхней рамки штампа не менее чем на **5...10 мм** (не допускается касание текста линий штампа).
   - При нехватке места над штампом ТТ размещают левее штампа колонками шириной не более 185 мм.
2. **Нумерация и заголовок:**
   - Если пунктов два и более, они нумеруются арабскими цифрами с точкой: `1.`, `2.`, `3.` и т.д.
   - Если пункт один, номер не ставится.
   - Заголовок `Технические требования` по ГОСТ 2.316 не пишется, если на чертеже нет других таблиц. Однако в машиностроительной практике допускается заголовок `Технические требования:` при наличии таблиц параметров (гибки, пружин, зубчатых колес).
3. **Справочные размеры:**
   - Если на чертеже проставлены размеры со звездочкой (`*`), первым пунктом ТТ всегда пишется:
     `1. *Размеры для справок.` (или `*Размер для справок.`, если такой размер один).
4. **Шрифт оформления:**
   - Стандартный чертежный шрифт ЕСКД: `ГОСТ тип А` (наклонный 15°).
   - Высота шрифта заметок ТТ: **3,5 мм** (для форматов А4, А3) или **5,0 мм** (для больших форматов А1, А0).

## 3. Специфика ТТ по технологическим переделам

### 3.1. Листовая обработка: Лазерная и плазменная резка
- **Особенности допусков:**
  Вместо универсального машиностроительного допуска для лазерного контура применяется международный и национальный стандарт **ГОСТ ИСО 9013-2017**:
  - Класс допуска 1: высокоточная лазерная резка тонколистового металла ($s \le 4$ мм).
  - Класс допуска 2: стандартная лазерная и прецизионная плазменная резка ($s = 4\dots 16$ мм).
- **Обязательные требования:**
  - Удаление грата, окалины и наплывов металла по контуру реза.
  - Притупление острых кромок (фаска 0,3...0,5 мм).
  - Указание на выполнение траектории по математической модели (программе ЧПУ).

### 3.2. Листовая гибка
- **Особенности:**
  - Неуказанные радиусы гибки должны соответствовать физическим параметрам матриц и пуансонов ($R = s$ для углеродистых сталей).
  - Параметры развертки (коэффициент нейтрального слоя $K pprox 0,38\dots 0,42$) являются справочными для заготовительного участка.
  - Направление волокон прокатки: при критических радиусах гибки линии гиба задаются перпендикулярно направлению проката.

### 3.3. Механическая обработка (Токарная и Фрезерная)
- **Общие допуски:**
  - Традиционная запись ЕСКД: `Общие допуски по ГОСТ 30893.1: H14, h14, ±t2/2.`
  - Современная комплексная запись: `Общие допуски: ГОСТ 30893.1-m, ГОСТ 30893.2-K.` (где $m$ — класс точности линейных размеров «средний», $K$ — класс допусков формы и взаимного расположения «средний»).
- **Специфические элементы:**
  - Центровые отверстия по ГОСТ 14034-74 (форма А или В).
  - Выходные канавки для шлифования по ГОСТ 8820-69.
  - Сбеги и фаски резьб по ГОСТ 10549-80.
  - Ограничение радиусов в углах карманов под радиус концевых фрез ЧПУ ($R \le 3$ мм под $arnothing 6$ мм).

### 3.4. Сварные конструкции (сварка в среде защитных газов)
- **Стандарты сварных соединений:**
  - **ГОСТ 14771-76** (дуговая сварка в защитных газах):
    - Способ `УП` — полуавтоматическая в углекислом газе ($CO_2$).
    - Способ `ИП` — полуавтоматическая в смеси газов ($80\% Ar + 20\% CO_2$).
    - Способ `АП` — автоматическая сварка плавящимся электродом.
    - Способ `ИНп` — аргонодуговая сварка неплавящимся электродом с присадочной проволокой (TIG).
  - **ГОСТ 23518-79** — швы под острыми и тупыми углами.
- **Материалы и допуски:**
  - Сварочная проволока Св-08Г2С по ГОСТ 2246-70 (для конструкционных сталей Ст3, 09Г2С, 20).
  - Общие допуски сварной металлоконструкции: класс `ГОСТ Р ИСО 13920-BF` (линейные размеры класс B, форма/углы класс F) или класс `ГОСТ Р ИСО 13920-CG`.
  - Контроль качества: ВИК 100% по ГОСТ Р ИСО 17637-2014, уровень дефектности C (или B) по ГОСТ Р ИСО 5817-2021.

## 5. Инструменты конструктора для работы с ТТ

### Способ 1: Интерактивный макрос SWPlus (`TT.SWP` / `TT.EXE`)
1. Открыть чертеж в SolidWorks.
2. Запустить макрос `TT.SWP` (или ярлык на панели инструментов SolidWorks).
3. В окне программы выбрать нужный профиль в списке **Профиль** (например, «Деталь: Лазерная резка + Гибка») или набрать требования вручную из категорий.
4. Нажать кнопку размещения ТТ — макрос автоматически спозиционирует блок над штампом.

### Способ 2: Автономный макрос `Добавление_ТТ_ГОСТ.swb`
- Легковесный скрипт SolidWorks Basic Macro, не требующий внешних окон.
- Автоматически вычисляет размер любого формата листа (А4..А0), удаляет старые ТТ и ставит актуальный блок шрифтом ГОСТ.

### Способ 3: Автоматизация через `apply_tt_profile.py`
Консольная утилита и API для пакетного нанесения:
```bash
# Просмотр списка профилей
python apply_tt_profile.py --list

# Нанесение профиля на активный чертеж
python apply_tt_profile.py --profile "Сборка: Сварная рамная конструкция из профильных труб"
```
