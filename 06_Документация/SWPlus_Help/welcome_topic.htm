Пакет макросов SWPlus 2017 сп.0.0 используется при работе в САПР SolidWorks и предназначен для облегчения работы конструктора по оформлению конструкторской документации в соответствии с ЕСКД.

Пакет макросов рассчитан на использование в небольшом конструкторском коллективе, работающем без ПДМ или с ПДМ без встроенного генератора текстовых документов по ЕСКД (например PDMWorks).

Пакет программ состоит из семи основных макросов:

1.MProp - для заполнения свойств моделей;

2.DProp - для управления листами чертежа;

3.SProp - для заполнения свойств моделей из разделов Стандартные изделия, Прочие изделия и Материалы;

4.SaveDRW - для "правильного" сохранения чертежа;

5.SaveAsPDF - для сохранения чертежа в формате PDF или TIFF;

6.Master - для создания шаблонов основных надписей;

7.SpecEditor – для генерации текстовых конструкторских документов.

и четырех дополнительных:

1.TT - для заполнения технических требований;

2.Roughness - для простановки знака неуказанной шероховатости в углу чертежа;

3.RecordDimM - для редактирования текста размеров.

4.CoolOut - для преобразования размеров, проставленных с помощью инструмента "Условное обозначение отверстия", к виду по ЕСКД.

Отдельные макросы из данного комплекта имеют меню с настройками, сохраняемыми в ini-файлах. Данные настройки позволяют включать\отключать различные дополнительные опции, влияющие на работу макросов.

Одной из особенностью данных макросов является то, что все изменения вносимые ими в документы SW осуществляются только штатными средствами самого SW. Т.е. чертеж или спецификация, оформленные с помощью данного комплекта макросов, могут быть открыты и даже отредактированы на компьютере без установленных макросов.

При разработке комплекта макросов имелись в виду определенные принципы работы в SW:

1. Один файл - одна деталь, сборка или чертеж;

2. Конфигурации верхнего уровня - исполнения. Имена конфигураций 00, 01, 02 и т.д. В этой связи удобно переименовать имя первой конфигурации в шалонах детали и сборки с "По умолчанию" в "00".

3. Имя файла чертежа детали должно совпадать с именем файла 3D модели детали;

4. Имя файла сборочного чертежа,  должно совпадать с именем файла 3D модели сборки;

5. Если по модели сборки кроме сборочного чертежа дополнительно оформляются габаритный, монтажный или прочие чертежи, то они должны создаваться в отдельных файлах. Имена этих файлов должны включать в себя код документа. Например, АБВГ.14.10.00ГЧ.slddrw.
