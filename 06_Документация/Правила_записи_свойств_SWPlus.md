# Правила записи свойств SWPlus

Документ пакета WP-1.1 плана согласования надстройки ЕСКД с SWPlus (ред. 4, раздел 6). Надстройка пишет каждое общее с
MProp свойство **ровно так, как его пишет MProp**, чтобы «Применить без правок» в MProp (и «Перезагрузка форматки» в
DProp, которая запускает MProp) ничего не меняло — критерий К-1, тесты `09_Тесты/tests/test_e2e_mprop.py` (M04, M19).

Ссылки `FrmMProp:2850` — строки текстовой выгрузки `03_Макросы_и_Плагины/Макросы_SW_ZTool/_VBA_выгрузка/MProp/FrmMProp.frm.txt`.
Строки формата надстройки собраны в `Core/SwPlusFormat.cs`; юнит-тесты сверяют их с этими строками выгрузки.
Обозначения: ⏎ — LF (`Chr$(10)`), ↵⏎ — CR LF. «Файл» — заголовок документа без расширения (`GetTitle` без `.SLDPRT`,
FrmMProp:1488–1495). Факты живого MProp — прогон `08_Результаты_Тестирования/runs/20260913_233935`.

## 1. Масса

| Свойство | Уровень | Значение | VBA |
|---|---|---|---|
| `Масса_ФБ` деталь | конфигурация | `<FONT size=1> ⏎<FONT size=3.5>"SW-Mass@@<конф>@<файл>.SLDPRT"`, при граммах в конце ` г` | 2850, 2856 |
| `Масса_ФБ` сборка | конфигурация | то же с `.SLDASM` | 2882, 2888 |
| `Масса_ФБ` при `prpFontSize` = 0 | конфигурация | без двух тегов FONT | 2852, 2884 |
| `Масса_Таблица` | конфигурация | `"SW-Mass@@<конф>@<файл>.SLDPRT"` (сборка — `.SLDASM`), расширение заглавными | 2862, 2894 |
| `Плотность_ФБ` деталь | конфигурация | `"SW-Density@@<конф>@<файл>.SLDPRT"` — пишет MProp, надстройка не пишет | 2830 |
| «-» и «См. таблицу» | конфигурация | `<FONT size=1> ⏎<FONT size=3.5>-`, `<FONT size=2.5>См.⏎таблицу` — значения пользователя, не трогаются | 2837, 2843 |

**Единицы массы документа** (FrmMProp:2449–2468, 3353–3368). Флаг `Единицы` в активной конфигурации: `False`/`0` —
единицы пользователя, не трогаются (2339); `True`/`-1` или нет свойства — по массе активной конфигурации: больше 0,1 кг —
`swUnitSystem_Custom`, длина м, масса кг, объём м³, 2 знака; иначе (0,1 кг и меньше) — см, г, см³, 1 знак. Единица одна на
документ, поэтому у всех конфигураций один суффикс (` г` или без суффикса). MProp при первом применении добавляет
`Единицы` = `True` (2760–2764).

| Свойство | Уровень | Значение | VBA |
|---|---|---|---|
| `Наименование` | общие | текст наименования (у БЧ — тоже одно название; строки записи — `Запись_БЧ`, раздел 6) | 2628–2633 |
| `Description` | общие | наименование одной строкой — служебное MProp | 2634–2635 |
| `Наименование_ФБ`, одна строка | общие | `<FONT size=4> ⏎<FONT size=5>` + текст | 2652 |
| `Наименование_ФБ`, две строки | общие | `<FONT size=2> ↵⏎<FONT size=5>` + текст с ⏎ между строками | 2645 |
| `Наименование_ФБ`, три строки | общие | `<FONT size=3.5>` + текст с ⏎ | 2640 |
| `Наименование_ФБ` при `prpFontSize` = 0 | общие | текст без FONT | 2656 |

Флажок формы «ChkFont» (3,5 мм вместо 5 мм, 2643, 2650) — состояние формы, в свойства не сохраняется: надстройка его не
использует. Граница переноса графы 1: одна строка шрифтом 5 мм — до 22 знаков (спайк S-4); длиннее — перенос по словам на
две строки; больше двух строк по 22 знака — три строки по 31 знаку шрифтом 3,5 мм (`SwPlusFormat.TitleLineLimit`,
`TitleSmallLineLimit`). MProp после правки WP-3.1 переносит так же (`SwpStampText`, `SwpWrapTitle` в конце FrmMProp).

## 3. Обозначение и исполнения

| Свойство | Уровень | Значение | VBA |
|---|---|---|---|
| `Обозначение` | общие | обозначение из имени файла (разделитель — первый пробел, строки 48–49 словаря) | 2541 |
| `Number` | общие | то же — служебное MProp | 2533–2534 |
| `Обозначение` исполнения | конфигурация | `<обозначение>-<номер>` при `Исполнение` = 1 или 2 | 2542–2544, 2677–2690 |
| `Исполнение` | конфигурация | `1` — галочки «Исполнение» и «Из»: имя конфигурации начинается с двузначного номера («01», «02 Покраска»); `2` — «Исполнение» без «Из»: номер у родителя («Покраска» под «01»), однозначный («1» → «-01») или трёхзначный («001», ГОСТ 2.201-80); `0` — базовая конфигурация или номер в имени файла. При каждой синхронизации (З-24), у детали БЧ — только в пустое | 1439–1456, 2603–2613 |
| `RenameSWP` | общие | `0` — обозначение выведено из имени файла; `1` — имя файла не «Обозначение Наименование» | 1530, 1550–1557 |

**Исполнение в имени файла** («ПРТИ.468211.116-01 Упор»): `Исполнение` = 0 — иначе MProp добавляет номер ещё раз
(«…-01-01», прогон 20260913_233935, M04 A-20).

**«1» только у двузначного номера.** MProp при «1» берёт номер из первого слова имени конфигурации, а SaveDRW и
SaveAsPDF — из двух первых знаков (SaveDRW_run:344–348, SaveAsPDF:408–412). У исполнения «001» они потребовали бы чертёж
«…-00» и отказались сохранить чертёж «…-001»; при «2» номер у всех трёх берётся из обозначения конфигурации.

## 4. Подписи

`Конструктор` (общие) и «Сводка → Автор» (`SummaryInfo(2)`) — одно и то же значение: MProp заполняет форму из «Автор»
(1906) и пишет его в оба места (2719–2724). Надстройка пишет оба, только в пустые (или при `OverwriteSignatures = 1`).
`Проверил`, `Контора` — конфигурация, только в пустые.

## 5. Сборки

| Свойство | Уровень | Значение | VBA |
|---|---|---|---|
| `Сборка1_ФБ` | конфигурация | код документа из поля формы; общую копию MProp удаляет | 3056–3058 |
| `Сборка2_ФБ` | конфигурация | `<FONT size=1> ⏎<FONT size=2.5>` + текст («Сборочный чертеж»); общую копию удаляет | 3060–3069 |

Надстройка `Сборка1_ФБ` не пишет и не удаляет (его ставят шаблон сборки «СБ» и MProp); прежнее « СБ» с пробелом
заменяет на «СБ». `Сборка2_ФБ` — только если свойства нет, а `Сборка1_ФБ` = «СБ»; прежнее «Сборочный чертёж» без разметки —
в формат MProp. У детали MProp добавляет `Сборка1_ФБ` = «» и `Сборка2_ФБ` = `<FONT size=1> ⏎<FONT size=2.5>`.

## 6. Материал

| Режим MProp | `Материал_ФБ` (конфигурация) | `Материал_Таблица` | VBA |
|---|---|---|---|
| Сортамент (дробь) | `<FONT size=1.8> <FONT size=3.5>` + вид + ` <STACK size=1>` + сортамент + `<OVER>` + марка + `</STACK>` | без FONT | 2932–2938 |
| Материал пользователя, одна строка | `<FONT size=1.8> ⏎<FONT size=3.5>` + текст | текст | 2913, 2918 |
| Материал пользователя, несколько строк | `<FONT size=5.0> <FONT size=3.5>` + текст с ⏎ | текст | 2911, 2918 |
| Материал SW (поля пустые) | `<FONT size=1.8> ⏎<FONT size=3.5>"SW-Material@@<конф>@<файл>.SLDPRT"` | выражение | 2921, 2925 |
| См. таблицу | `<FONT size=1.8> ⏎<FONT size=3.5>См. таблицу` | — | 2942 |

Материал из библиотеки ЕСКД — источник истины (Р-5): запись библиотеки заменяет дробь MProp, текст и выражение SW-Material
(Р-6); «-» и «См. таблицу» остаются за пользователем. Общую копию `Материал_ФБ` MProp удаляет (2904).

## 7. Безчертёжная деталь (БЧ)

| Свойство | Уровень | Значение | VBA |
|---|---|---|---|
| `Формат` | активная конфигурация; общие — при одной конфигурации | `БЧ` | 3042–3053 |
| `Примечание` | то же | `"SW-Mass@@<конф>@<файл>.SLDPRT" кг` или ` г` (единица документа) | 3029–3038 |
| `Наименование` | общие | одно название (З-9) | 2628–2633: MProp пишет и читает его как у любой детали |
| `Запись_БЧ` | общие при одной конфигурации, иначе активная | строки записи после названия: дробь материала ⏎ размеры | нет — свойство надстройки; SpecEditor читает его временной графой таблицы (З-9); правки WP-3.2 для записи в `Наименовании` остаются для записей прежних версий |

Режим «масса в Примечании» MProp включает, когда в поле «Примечание» формы стоит слово «Масса» (3030). Вид записи в
спецификации — решение Р-15 (S-2f): каждая строка записи — строка спецификации 8 мм, дробь в объединённой ячейке на две
строки; оформляет SpecEditor (WP-4.3).

## 8. Уровни и общие копии

MProp пишет в активную конфигурацию и удаляет общие копии конфигурационных свойств (`Масса_ФБ` 2834, `Материал_ФБ` 2904,
`Сборка1_ФБ` 3056, `Сборка2_ФБ` 3060). `Формат`, `Примечание`, `Раздел` — в конфигурации; общая копия только у документа с
одной конфигурацией (3046–3053). Надстройка общих копий конфигурационных свойств не создаёт и не поддерживает.
Эти три свойства MProp при каждом «Применить» удаляет и дописывает в конец в порядке `Примечание`, `Формат`, `Раздел`
(3021–3053) — поэтому в едином порядке свойств надстройки они последние, и MProp порядок не меняет (руководство, 2.3).

## 9. Что MProp добавляет при первом применении

Перечень, который К-1 допускает (добавление с этими значениями ничего не меняет в документе):

- общие: `Number`, `Description`, `RenameSWP`, `Доп.свойство_1` «», `Доп.свойство_2` «», `Заимствование` «»,
  `Классификатор` «False», `Наименование2` «», `Обозначение2` «», `Примечание` «», `Проект_ФБ` «», `Раздел`,
  `Сборка` «False»/«True», `Удален` «НЕТ»;
- конфигурация: `Единицы` «True», `Заготовка` «», `Код_ФБ` «», `Литера_Таблица` «», `Литера_ФБ`
  `<FONT size=1> ⏎<FONT size=3.5>`, `Начальник` «», `Нормоконтроль` «», `Плотность_ФБ`, `Применение2` «», `Примечание` «»,
  `Проект` «», `Раздел`, `Сборка1_ФБ` «», `Сборка2_ФБ` `<FONT size=1> ⏎<FONT size=2.5>`, `Справочный_номер` «»,
  `Техконтроль` «», `Утвердил` «», `Формат` (значение общего), `Формат_ФБ` «False», `Характер_работы` «», `Материал_ФБ`
  и `Материал_Таблица` «» у сборки.

У детали без материала в активной конфигурации MProp в режиме «материал SW» вписывает в пустую графу 3
`<FONT size=1.8> ⏎<FONT size=3.5>"SW-Material@@<конф>@<файл>.SLDPRT"` и то же выражение в `Материал_Таблица` (2921, 2925).
Надстройка конфигурации без материала ничего не пишет (решение Д-33), поэтому К-1 это добавление допускает.

Известный дрейф MProp (не ошибка надстройки): пустая «Контора» получает первую строку справочника `MProp_Firm.txt`
(1462–1485); пустая литера — разметку `Литера_ФБ`.

## 11. Эталон основной надписи (Р-12, WP-4.6)

Надписи формы 1 стоят так, чтобы разметка MProp (её же пишет надстройка) ложилась в свои графы у детали и у сборки.
Якоря — мм над нижним краем листа; одинаковы во всех форматках листа 1, шаблоне «Чертеж.drwdot» и
`Master_Template_Sheet1` (штамп привязан к правому нижнему углу, меняется только x).

| Надпись | Графа | Шрифт | Якорь y | Интервал |
|---|---|---|---|---|
| MYPRP0 | 2 — обозначение + «Сборка1_ФБ» | 7 мм | **55,4** (было 56,8) | 1 мм |
| MYPRP4 | 1 — наименование (1–2 строки 5 мм, 3 строки 3,5 мм), ширина 0,95 | 5 мм | **44,5** (было 36,0) | 2 мм |
| MYPRP3 | 1 — «Сборочный чертеж» | 2,5 мм | **26,0** (было 27,52) | 1 мм |
| MYPRP15 | 5 — масса | 3,5 мм | **38,0** (было 34,7) | **2 мм** (было 1) |
| MYPRP16 | 3 — материал | 1,8 мм | 19,2 | 2 мм |

Шрифт всех надписей — «GOST 2.304 type A» (Р-14, `09_Тесты/tools/switch_font.py`; «GOST type A» рисовал «×» буквой

(допуск 0,5 мм), обозначение и масса по центру графы (±1 мм), наименование выше «Сборочный чертеж» (зазор от 0,3 мм).
