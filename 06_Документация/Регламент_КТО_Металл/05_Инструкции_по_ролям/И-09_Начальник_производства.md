# Инструкция И-09. Начальник производства

**Для кого:** начальник производства; заместитель — по отдельному распоряжению.
**Основание:** Регламент КТО «Металл» v2.2 — §2.8 (процедура Е), часть 5, часть 6.
**Дата:** 14 сентября 2026 г.
**Утверждает:** Начальник КТО / Главный конструктор Лунин В. В.

---

## 1. Что вам доступно

Вы просматриваете через браузер, без установки программ:

| Папка | Что в ней |
| :--- | :--- |
| `02_БАЗА` | утверждённые эталоны стандартных изделий: чертежи PDF, файлы ЧПУ, техкарты, паспорта; история изменений каждого изделия; извещения об изменении |
| `04_ПРОИЗВОДСТВО` | выданные в цех заказы: заявка на производство, чертежи и файлы ЧПУ |

Права — **только чтение**: просмотр и скачивание. Загрузить, изменить или удалить файл нельзя.

Незавершённые заказы КТО (`03_ЗАКАЗЫ`) вам не показываются намеренно: пока документы не утверждены и не выданы, работать по ним нельзя.

## 2. Как войти

1. На компьютере в сети предприятия открыть браузер (Chrome, Edge, Firefox).
2. Адрес: **`https://nas-kto:5001`**. Если браузер предупреждает о сертификате — сообщить сисадмину, не продолжать на чужом компьютере.
3. Ввести логин и пароль, выданные сисадмином.
4. Открыть **File Station** → общая папка `KTO`.
5. Закончив, нажать значок пользователя справа вверху → «Выйти».

Доступ работает только из сети предприятия. С домашнего компьютера и телефона через интернет доступа нет.

## 3. Как найти документы

**Стандартное изделие:** `KTO` → `02_БАЗА` → раздел (`01_Столы`, `02_Стулья`, `03_Стеллажи`, `04_Торговое`) → шифр изделия, например `СТД-СЛ120.00`:

| Папка или файл | Что это |
| :--- | :--- |
| `02_PDF\` | чертежи |
| `03_ЧПУ\` | файлы для лазера (DXF) и трубореза (IGS) |
| `04_Тех\` | паспорт, схема сборки, упаковочный лист |
| `Техкарта_СТД-СЛ120.00_на_1шт.xlsx` | нормы на 1 шт по участкам |
| `История_изменений.xlsx` | все изменения изделия с номерами и датами |
| `_Аннулировано\`, `_Версии\` | прежние ревизии — только для справки |

**Заказ в производстве:** `KTO` → `04_ПРОИЗВОДСТВО` → папка заказа, например `250-АСТ_Школа12` → `Заявка_250-АСТ.xlsx` и папки изделий.

**Извещения об изменении стандартных изделий:** `02_БАЗА` → `_Извещения` → `Книга_регистрации_ИИ.xlsx` (перечень и статусы) и PDF извещений.

**Просмотр и печать:**

- PDF — двойной щелчок открывает просмотр в браузере; печать из просмотра.
- Excel — выделить файл → «Скачать» → открыть в Excel на своём компьютере.
- Модели SolidWorks (`.sldprt`, `.sldasm`) в браузере не открываются и вам не нужны.

## 4. Как понять, что документ действующий

1. Действует файл с **наибольшим номером** `_ИзмN` в имени: `…_Изм1.pdf` заменяет `…_Изм0.pdf`.
2. Файлы в папках `_Аннулировано` и `_Версии` — **недействующие**.
3. Для заявки то же: `Заявка_250-АСТ_Изм1.xlsx` заменяет `Заявка_250-АСТ.xlsx`.
4. Статус изменения стандартного изделия — в книге регистрации извещений: «Утверждено» — к исполнению, «Внедрено» — файлы в папках уже заменены.

## 5. Если вы нашли ошибку или хотите изменение

| Ситуация | Кому и как |
| :--- | :--- |
| Ошибка в чертеже, из-за которой будет брак | остановить операцию через мастера; сразу сообщить Начальнику КТО и технологу |
| Предложение улучшить стандартное изделие | письмом или устно Начальнику КТО: шифр изделия, что изменить, почему. КТО заносит предложение в книгу регистрации и сообщает решение |
| Заявка не совпадает с чертежами | технологу |
| Не открывается папка или файл | сисадмину: какая папка, что за сообщение |

## 6. Безопасность

- Не передавать логин и пароль, не сохранять пароль в браузере на общих компьютерах.
- Выходить из File Station после работы.
- Скачанные документы не пересылать за пределы предприятия без согласования с Начальником КТО.
