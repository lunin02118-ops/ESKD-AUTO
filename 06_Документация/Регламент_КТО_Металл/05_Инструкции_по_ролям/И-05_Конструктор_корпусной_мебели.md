# Инструкция И-05. Конструктор корпусной мебели

**Для кого:** конструкторы направления «Корпус», работающие в bCAD.
**Основание:** Регламент КТО «Металл» v2.2 — §1.2–1.3, §2.8, часть 6. Порядок проектирования в bCAD — отдельный регламент направления «Корпус».
**Дата:** 14 сентября 2026 г.
**Утверждает:** Начальник КТО / Главный конструктор Лунин В. В.

---

## 1. Ваша роль

Вы проектируете позиции служебной записки с направлением `КОРПУС` и корпусную часть изделий `КОМБИ`, любой стандартности: `СТД` берётся из эталона, `ТИПОВОЕ` дорабатывается из эталона, `НЕСТАНДАРТНОЕ` разрабатывается с нуля. Данные вашего направления хранятся в той же общей папке КТО и подчиняются тем же правилам хранения, доступа и изменений, что и металл.

Для изделий `КОМБИ` вы делаете корпусную часть в папке `01_Корпус\<изделие>\`; кто финализирует общую сборку и техкарту изделия, конструкторы решают сами и отмечают в задаче Битрикс24.

## 2. Ваши папки и права

| Папка | Права |
| :--- | :--- |
| `Z:\03_ЗАКАЗЫ\<заказ>\01_Корпус\` | чтение и запись — выдаёт Начальник КТО по задаче в Битрикс24 |
| `Z:\03_ЗАКАЗЫ\<заказ>\` (остальное), `Z:\02_БАЗА`, `Z:\04_ПРОИЗВОДСТВО` | чтение |
| `02_Металл\` любого заказа | только чтение, не изменять |

## 3. Правила работы

1. Файлы bCAD заказа хранятся только в `01_Корпус\` папки заказа. Рабочий стол, `C:\` и флешки для хранения не используются.
2. Работа с `Z:` по сетевому кабелю; при пропадании сети не сохранять, пока `Z:` не появится снова.
3. Имена папок — без пробелов и точек; полный путь к файлу — не длиннее 200 символов.
4. Задача, срок и ход работ — в Битрикс24; классификация позиций — в `Разметка_СЗ.xlsx` заказа (заполняет Начальник КТО). Папку изделия в `01_Корпус\` создаёт скрипт Начальника КТО: `01_bCAD\`, `02_PDF\`, `03_ЧПУ\`, `04_Тех\`, `_Аннулировано\`.
5. Перед сдачей — проверка Начальником КТО или ведущим конструктором направления «Корпус».

## 4. Выдача в производство

Утверждённые файлы (чертежи, карты раскроя, спецификации) Начальник КТО или технолог копирует в `Z:\04_ПРОИЗВОДСТВО\<заказ>\Корпус\`. С этого момента документы выданы.

Имена выдаваемых файлов содержат номер ревизии: первая выдача — `_Изм0`, каждое изменение — `_Изм1`, `_Изм2`…

## 5. Изменения после выдачи

1. Запись в `Журнал_изменений.xlsx` заказа, лист «Изменения»: номер `Ж-<заказ>-N`, дата, файл, было → стало, что делать с уже изготовленными деталями. Статус «В работе».
2. Если деталь уже в работе и ошибка даст брак — сразу мастеру участка и Начальнику КТО.
3. Исправить файлы, выпустить новые с `_ИзмN`; прежние — в `_Аннулировано\` рядом.
4. Начальник КТО или технолог заменяет файлы в `04_ПРОИЗВОДСТВО`, в журнале отметка «Внедрено».

Ошибка до выдачи в производство исправляется без записи.

## 6. Если что-то пошло не так

| Ситуация | Действие |
| :--- | :--- |
| Нет прав на запись в `01_Корпус` | Начальнику КТО |
| Файл испорчен или удалён по ошибке | Проводник → ПКМ по папке → «Предыдущие версии» → восстановить; сообщить сисадмину |
| Пропал `Z:` | не сохранять; проверить кабель; сообщить сисадмину |

## 7. Нельзя

- Хранить файлы заказа вне папки заказа.
- Изменять папку `02_Металл` и эталоны.
- Менять выданные документы без записи в журнале изменений заказа.
