# Задание системному администратору: права КТО на Synology

**Кому:** системному администратору, обслуживающему сетевой диск `Z:`.
**От кого:** Начальник КТО / Главный конструктор Лунин В. В.
**Дата:** 19 сентября 2026 г. Редакция 3 (заменяет редакцию 2 от 15.09.2026: диск один — `Z:`; отдельной общей папки
архива и диска `Y:` нет, архив — папка `_Архив` внутри папки КТО; снимки и резервная копия — только нужных папок).
**Время:** около 40 минут.

---

## Что нужно

Стандартные права на папки отдела группами, один раз. Никакого делегирования администрирования, никаких прав администратора NAS Начальнику КТО. Дальше права меняются только по его письменной просьбе (новый сотрудник, закрытый заказ).

Ниже «папка КТО» — общая папка `\\Synology_TR\Конструкторский отдел`, подключённая сотрудникам как диск `Z:`. Другого
диска нет.

Имена подпапок в этом задании — как на сервере. В регламенте они называются условно:

| В регламенте | На сервере (внутри папки КТО) |
| :--- | :--- |
| `00_ИНСТРУМЕНТЫ` | `_Библиотека проектирования\_инструменты_конструктора` |
| `01_БИБЛИОТЕКА` | `_Библиотека проектирования` (в том числе `_ крепеж и фурнитура`) |
| `02_БАЗА` | `_Библиотека проектирования\_стандартные изделия` |
| `03_ЗАКАЗЫ` | `_Заявки` |
| архив | `_Архив` (уже создана, раздел 3) |

## 1. Группы

Панель управления → Пользователь и группа → Группа. Создать (если нет) и включить сотрудников по списку Начальника КТО:

| Группа | Кто |
| :--- | :--- |
| `kto_head` | Начальник КТО |
| `kto_tech` | технолог, нормоконтроль |
| `kto_curator` | куратор баз |
| `kto_design` | инженеры-конструкторы (металл, корпус) |
| `kto_toolkit` | администратор инструментария (кто публикует `_инструменты_конструктора`; сейчас — Начальник КТО) |
| `prod_view` | мастера, операторы ЧПУ, склад, ОМТС, начальник производства |

Личная учётная запись у каждого; общих учёток нет. У всех снять флажок «Запретить пользователю изменять пароль», чтобы выданный пароль сменили на свой.

## 2. Права на папку КТО (`Z:`)

Панель управления → Общая папка → папка КТО → Изменить → Разрешения: группам КТО — «Чтение/запись», `prod_view` — «Только чтение». Затем File Station → папка КТО → подпапка → ПКМ → Свойства → Разрешение — по таблице (применять к папке, дочерним папкам и файлам):

| Подпапка | Чтение/запись | Только чтение | Нет доступа |
| :--- | :--- | :--- | :--- |
| `_Библиотека проектирования\_инструменты_конструктора` | `kto_toolkit` | все остальные группы КТО | `prod_view` |
| `_Библиотека проектирования` (остальное) | `kto_curator` | `kto_head`, `kto_tech`, `kto_design` | `prod_view` |
| `_Библиотека проектирования\_стандартные изделия` | `kto_curator` | `kto_head`, `kto_tech`, `kto_design`, `prod_view` | — |
| `_Заявки` | `kto_head`, `kto_tech`, `kto_design` | `kto_curator`, `prod_view` | — |
| `_Архив` | `kto_head` | — | все остальные группы |

Папки «Производство» (`_Производство`) нет (ТЗ-04, 18.09.2026): цех получает PDF листов участков и чертежей прямо в
папке изделия (`<заказ>\02_Металл\И<nn>_…\02_PDF`, файлы ЧПУ — `03_ЧПУ`). Поэтому `prod_view` получает **только
чтение** на `_Заявки` целиком — выдавать права на каждую `02_PDF` отдельно нельзя, их сотни и они появляются каждый день.
Что выдано в цех, видно по отметке `_Выдано_<дата>.txt` в папке изделия. Если Начальник КТО решит скрыть от цеха
черновики — вариант на выбор сисадмина (скрипт на NAS, который по `_Выдано_*.txt` даёт `prod_view` чтение на папку
изделия), согласовать отдельно.

Тип разрешений везде «Разрешить». Тип «Запретить» не использовать. «Нет доступа» — просто не давать группе запись в разрешения подпапки.

## 3. Архив — папка `_Архив`

Папка `_Архив` в корне папки КТО (рядом с `_Заявки`) **уже создана** Начальником КТО 19.09.2026 и проверена закрытием
тестового заказа; сейчас права на неё унаследованы от папки КТО — их нужно сузить. Кнопка «Закрыть заказ» надстройки ЕСКД сама находит её
рядом с `_Заявки` и складывает туда сданные заказы: `_Архив\<год>\<заказ>`. Права: `kto_head` — «Чтение/запись» (в том
числе удаление — это обычное право записи, отдельно ничего не отнимать); остальным группам — не давать (наследование
прав от папки КТО на `_Архив` отключить). Защита от удаления (WriteOnce / WORM) **не включается**: защита архива —
снимки и резервная копия (раздел 4).

## 4. Снимки, резервная копия, SMB

Снимки нужны не всей папке КТО, а только папкам с работой отдела: **`_Заявки`, `_Архив`, `_Библиотека
проектирования`** (список утверждает Начальник КТО; остальное в папке КТО — на его усмотрение).

Важно: Snapshot Replication делает снимки **общей папки целиком**, отдельные подпапки в снимок не выбираются. Поэтому
одно из двух — выбрать и сообщить Начальнику КТО:
* **а)** снимки всей папки КТО (на Btrfs снимок хранит только изменения — лишние папки почти ничего не стоят);
* **б)** вынести папки, которым снимки не нужны, в отдельную общую папку и делать снимки только папки КТО.

| № | Где в DSM | Что сделать |
| :---: | :--- | :--- |
| 1 | Snapshot Replication → Снимки → папка КТО | каждый час; хранить не менее 48 часовых и 30 суточных; «Сделать снимки видимыми» — да |
| 2 | Hyper Backup | в задании отметить только `_Заявки`, `_Архив`, `_Библиотека проектирования` — на отдельный носитель по расписанию (ежедневно ночью); проверить восстановление одного файла |
| 3 | Панель управления → Файловые службы → SMB → Дополнительно | SMB3 включён; opportunistic locking включён; «Enable Windows ACL» для папки КТО — включено |
| 4 | Панель управления → Привилегии приложений | `prod_view` — File Station «Разрешить» (для просмотра через браузер); группам КТО — File Station «Разрешить» |
| 5 | Synology Drive, Cloud Sync и любые синхронизаторы | на папке КТО **не включать** — SolidWorks с ними не работает |

## 5. Не делать

- Не включать Начальника КТО в группу `administrators`; не делегировать ему роли администрирования.
- Не включать «Расширенные разрешения общего доступа» (Общая папка → Изменить → Расширенные разрешения): второй слой прав, с ним каждую выдачу пришлось бы делать дважды.
- Не менять права по просьбе конструкторов — только по письму Начальника КТО.
- Не давать `prod_view` запись в `_Заявки` — только чтение.
- Не заводить второй сетевой диск для архива.

## 6. Проверить вместе с Начальником КТО (10 минут)

1. Конструктор под своей учёткой создаёт файл в `_Заявки\_тест\` — можно; в `_Библиотека проектирования\_стандартные изделия` — нельзя.
2. Куратор пишет в `_Библиотека проектирования`; в `_Заявки` — нет.
3. Технолог пишет в `_Заявки`.
4. Начальник КТО создаёт и удаляет папку в `_Архив`; конструктор `_Архив` не открывает.
5. Мастер под учёткой из `prod_view` открывает `_Заявки\_тест\…\02_PDF` и `_стандартные изделия` только на чтение (и по SMB, и в File Station); записать не может.
6. Удалённый тестовый файл из `_Заявки\_тест` возвращается из снимка часовой давности.
7. Тестовую папку удалить.
