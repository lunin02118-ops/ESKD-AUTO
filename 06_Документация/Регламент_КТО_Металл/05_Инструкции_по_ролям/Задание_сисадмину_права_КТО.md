# Задание системному администратору: права КТО на Synology

**Кому:** системному администратору, обслуживающему сетевые диски `Z:` и `Y:`.
**От кого:** Начальник КТО / Главный конструктор Лунин В. В.
**Дата:** 15 сентября 2026 г. Редакция 2 (заменяет редакцию от 14.09.2026: делегирование администрирования отменено — только стандартные права групп).
**Время:** около 40 минут.

---

## Что нужно

Стандартные права на папки отдела группами, один раз. Никакого делегирования администрирования, никаких прав администратора NAS Начальнику КТО. Дальше права меняются только по его письменной просьбе (новый сотрудник, закрытый заказ).

Ниже «папка КТО» — общая папка, подключённая сотрудникам как диск `Z:`; «архив» — общая папка, подключённая Начальнику КТО как диск `Y:`.

## 1. Группы

Панель управления → Пользователь и группа → Группа. Создать (если нет) и включить сотрудников по списку Начальника КТО:

| Группа | Кто |
| :--- | :--- |
| `kto_head` | Начальник КТО |
| `kto_tech` | технолог, нормоконтроль |
| `kto_curator` | куратор баз |
| `kto_design` | инженеры-конструкторы (металл, корпус) |
| `kto_toolkit` | администратор инструментария (кто публикует `00_ИНСТРУМЕНТЫ`; сейчас — Начальник КТО) |
| `prod_view` | мастера, операторы ЧПУ, склад, ОМТС, начальник производства |

Личная учётная запись у каждого; общих учёток нет. У всех снять флажок «Запретить пользователю изменять пароль», чтобы выданный пароль сменили на свой.

## 2. Права на папку КТО (`Z:`)

Панель управления → Общая папка → папка КТО → Изменить → Разрешения: группам КТО — «Чтение/запись», `prod_view` — «Только чтение». Затем File Station → папка КТО → подпапка → ПКМ → Свойства → Разрешение — по таблице (применять к папке, дочерним папкам и файлам):

| Подпапка | Чтение/запись | Только чтение | Нет доступа |
| :--- | :--- | :--- | :--- |
| `00_ИНСТРУМЕНТЫ` | `kto_toolkit` | все остальные группы КТО | `prod_view` |
| `01_БИБЛИОТЕКА` | `kto_curator` | `kto_head`, `kto_tech`, `kto_design` | `prod_view` |
| `02_БАЗА` | `kto_curator` | `kto_head`, `kto_tech`, `kto_design`, `prod_view` | — |
| `03_ЗАКАЗЫ` | `kto_head`, `kto_tech`, `kto_design` | `kto_curator`, `prod_view` | — |

**Изменение 18.09.2026 (ТЗ-04 Р4-2, Р4-7).** Папки `04_ПРОИЗВОДСТВО` (`_Производство`) нет: цех получает PDF листов участков
и чертежей прямо в папке изделия (`<заказ>\02_Металл\И<nn>_…\02_PDF`, файлы ЧПУ — `03_ЧПУ`). Поэтому `prod_view` получает
**только чтение** на `03_ЗАКАЗЫ` целиком — выдавать права на каждую `02_PDF` отдельно нельзя, их сотни и они появляются
каждый день. Что выдано в цех, видно по отметке `_Выдано_<дата>.txt` в папке изделия. Если Начальник КТО решит скрыть
от цеха черновики — вариант на выбор сисадмина (скрипт на NAS, который по `_Выдано_*.txt` даёт `prod_view` чтение на
папку изделия), согласовать отдельно.

Тип разрешений везде «Разрешить». Тип «Запретить» не использовать. «Нет доступа» — просто не давать группе запись в разрешения подпапки.

## 3. Права на архив (`Y:`)

Отдельная общая папка «архив» (не подпапка папки КТО). Разрешения: `kto_head` — «Чтение/запись» (в том числе удаление — это обычное право записи, отдельно ничего не отнимать); остальные группы — без доступа. Защита от удаления (WriteOnce / WORM) **не включается**: защита архива — снимки и резервная копия (раздел 4).

## 4. Снимки, резервная копия, SMB

| № | Где в DSM | Что сделать |
| :---: | :--- | :--- |
| 1 | Snapshot Replication → Снимки → папка КТО и архив | каждый час; хранить не менее 48 часовых и 30 суточных; «Сделать снимки видимыми» — да |
| 2 | Hyper Backup | папка КТО и архив — на отдельный носитель по расписанию (ежедневно ночью); проверить восстановление одного файла |
| 3 | Панель управления → Файловые службы → SMB → Дополнительно | SMB3 включён; opportunistic locking включён; «Enable Windows ACL» для папок КТО и архива — включено |
| 4 | Панель управления → Привилегии приложений | `prod_view` — File Station «Разрешить» (для просмотра через браузер); группам КТО — File Station «Разрешить» |
| 5 | Synology Drive, Cloud Sync и любые синхронизаторы | на папках КТО и архива **не включать** — SolidWorks с ними не работает |

## 5. Не делать

- Не включать Начальника КТО в группу `administrators`; не делегировать ему роли администрирования.
- Не включать «Расширенные разрешения общего доступа» (Общая папка → Изменить → Расширенные разрешения): второй слой прав, с ним каждую выдачу пришлось бы делать дважды.
- Не менять права по просьбе конструкторов — только по письму Начальника КТО.
- Не давать `prod_view` запись в `03_ЗАКАЗЫ` — только чтение.

## 6. Проверить вместе с Начальником КТО (10 минут)

1. Конструктор под своей учёткой создаёт файл в `03_ЗАКАЗЫ\_тест\` — можно; в `02_БАЗА` — нельзя.
2. Куратор пишет в `02_БАЗА` и `01_БИБЛИОТЕКА`; в `03_ЗАКАЗЫ` — нет.
3. Технолог пишет в `03_ЗАКАЗЫ`.
4. Начальник КТО создаёт и удаляет папку в архиве `Y:`; конструктор архив не видит.
5. Мастер под учёткой из `prod_view` открывает `03_ЗАКАЗЫ\_тест\…\02_PDF` и `02_БАЗА` только на чтение (и по SMB, и в File Station); записать не может.
6. Удалённый тестовый файл возвращается из снимка часовой давности.
7. Тестовую папку удалить.
