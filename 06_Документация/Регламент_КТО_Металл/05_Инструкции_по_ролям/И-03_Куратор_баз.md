# Инструкция И-03. Куратор баз

**Для кого:** сотрудник КТО, назначенный держателем эталонов стандартных изделий, библиотеки проектирования и библиотеки материалов.
**Основание:** Регламент КТО «Металл» v2.2 — §1.2, §4.2–4.3, §4.6–4.7, часть 6.
**Дата:** 14 сентября 2026 г.
**Утверждает:** Начальник КТО / Главный конструктор Лунин В. В.

---

## 1. Ваша роль

Вы — держатель подлинников эталонов. Никто, кроме вас и назначенного Начальником КТО исполнителя, эталоны не меняет.

1. Эталоны серийных изделий `Z:\02_БАЗА` — ввод новых, изменения по извещениям, история изменений.
2. Библиотека проектирования `Z:\01_БИБЛИОТЕКА` — крепёж, покупные изделия, Toolbox.
3. Библиотека материалов ГОСТ — пополнение по заявкам конструкторов.
4. Книга регистрации извещений об изменении.

## 2. Ваши папки и права

| Папка | Права |
| :--- | :--- |
| `Z:\01_БИБЛИОТЕКА`, `Z:\02_БАЗА` | чтение и запись (группа `kto_kurator`) |
| остальное в `Z:\` | чтение |

Рабочее место настраивается как у конструктора (И-04, раздел 2).

## 3. Ввод нового эталона

1. Изделие принято Начальником КТО как серийное.
2. Папка: `Z:\02_БАЗА\<раздел>\<шифр>\` с подпапками `01_3D`, `02_PDF`, `03_ЧПУ`, `04_Тех`, `_Версии`; файл `История_изменений.xlsx` из `Z:\00_ИНСТРУМЕНТЫ\Шаблоны_изменений\`.
3. Имена файлов: деталь `СТД-СЛ120.10.01 Столешница.sldprt`, сборка `СТД-СЛ120.00 СБ Стол ученический.sldasm`; без подчёркиваний.
4. Типоразмеры — исполнения по конфигурациям `00`, `01`, `02` (обозначения `-01`, `-02` надстройка ЕСКД пишет сама).
5. Перенос моделей из заказа — только через Pack and Go с новыми именами, не Проводником.
6. Проверки как при приёмке (И-01, раздел 3, шаг 5), нормоконтроль технолога.
7. PDF, DXF, IGS с суффиксом `_Изм0`; техкарта `Техкарта_<шифр>_на_1шт.xlsx` с блоком на каждое исполнение.
8. Первая строка в `История_изменений.xlsx`: «Изм. 0, ввод эталона, дата, основание».

## 4. Новое покупное изделие в библиотеку

1. Начальник КТО решил, что изделие серийное.
2. Модель очищается: одно тело, свойства оформлены макросом SProp (`Раздел` = «Прочие изделия», поставщик, код), паспорт в PDF рядом.
3. Сохранение в `Z:\01_БИБЛИОТЕКА\02_Прочие\<группа>\`.
4. **Перенос из заказа — только средствами SolidWorks:** открыть сборку заказа → Файл → Найти ссылки → «Копировать файлы» или замена компонента на библиотечный → сохранить сборку. Перемещение Проводником рвёт ссылки у всех, кто открывает эту сборку.
5. Проверить у сборки заказа «Ссылки…»: компонент берётся из `01_БИБЛИОТЕКА`.

## 5. Новый материал в библиотеку материалов

1. Заявка от конструктора: сортамент, марка, стандарты.
2. Добавить строку в `04_Библиотеки_Материалов_и_Профилей\Библиотека материалов\Ограничительный_перечень_ТРОЯ.csv` репозитория инструментария (категория, имя в дереве, числитель-сортамент, знаменатель-марка, типоразмер, ГОСТ сортамента, марка, ГОСТ материала, штриховка).
3. Сгенерировать библиотеку по `README_Инструкция.md` в той же папке.
4. Прогнать автотест `python 09_Тесты/run_tests.py static` — проверяется согласованность полей и уникальность `matid`.
5. Передать сисадмину на публикацию. Правка `.sldmat` вручную на `Z:` запрещена.

## 6. Изменение эталона по извещению

Порядок назначает Начальник КТО. Вы — исполнитель или контролёр исполнителя.

1. **Предложение** на листе «Предложения» книги `Z:\02_БАЗА\_Извещения\Книга_регистрации_ИИ.xlsx` уже есть; решение Начальника КТО и номер `ИИ-КТО-2026-NNN` записаны.
2. **Предупредить конструкторов**, что эталон меняется; убедиться через контекстное меню «Кто открыл», что файлы свободны.
3. **Сохранить прежнюю ревизию.** Для каждого изменяемого чертежа: открыть чертёж → Файл → Pack and Go → ☑ «Сохранить в одну папку» → `<эталон>\_Версии\Изм<N-1>\` → «Сохранить».
4. **Внести изменения** в модель и чертёж и во все связанные документы: DXF, IGS, сборочный чертёж и спецификацию при изменении состава, техкарту при изменении норм.
   - Если взаимозаменяемость нарушена — создать новое исполнение или документ с новым обозначением; старое не трогать.
5. **Ревизия:**
   - таблица изменений основной надписи: «Изм.» — номер, «Лист» — прочерк, «№ докум.» — `ИИ-КТО-2026-NNN`, подпись, дата (пока заметками вручную);
   - новые PDF, DXF, IGS с суффиксом `_ИзмN`; прежние — в `02_PDF\_Аннулировано\` и `03_ЧПУ\_Аннулировано\`.
6. **Технолог** даёт указание о заделе и правит техкарту (И-06).
7. **Извещение** `ИИ-КТО-2026-NNN.xlsx` по шаблону: причина и код, взаимозаменяемость, задел, внедрение, применяемость, рассылка, было → стало. Подписи «Составил», «Нормоконтроль», утверждение Начальника КТО. PDF — в `_Извещения\`.
8. **Внедрение:** разослать извещение мастерам, технологу, ОМТС, исполнителям затронутых заказов; строка в `История_изменений.xlsx`; статус «Внедрено» в книге регистрации.

Коды причин: 1 — конструктивное улучшение, 2 — технологическое, 3 — унификация, 4 — изменение стандартов и ТУ, 5 — по результатам испытаний, 7 — устранение ошибок, 8 — улучшение качества, 9 — требование заказчика, 16 — изменение норм расхода.

## 7. Если что-то пошло не так

| Ситуация | Действие |
| :--- | :--- |
| Файл эталона открыт конструктором | попросить закрыть; не сохранять поверх |
| После изменения эталона у заказа сломались сопряжения | сообщить Начальнику КТО и исполнителю заказа; проверить, не нарушена ли взаимозаменяемость (тогда нужно было новое исполнение) |
| Ошибка в уже внедрённом извещении | новое извещение; прежнее не править |
| Перенесли файл Проводником, у сборок «файл не найден» | вернуть файл на место (корзина или «Предыдущие версии»), перенести средствами SolidWorks |

## 8. Нельзя

- Менять эталон без извещения и решения Начальника КТО.
- Переименовывать и перемещать файлы эталонов и библиотеки Проводником.
- Удалять прежние ревизии из `_Версии` и `_Аннулировано`.
- Править библиотеку материалов прямо на `Z:`.
