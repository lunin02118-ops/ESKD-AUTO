# Инструкция И-07. Мастер участка и оператор ЧПУ

**Для кого:** мастера заготовительного, сварочного, малярного и сборочного участков; операторы лазерной резки листа и трубореза.
**Основание:** Регламент КТО «Металл» v2.2 — §4.9, §5.2, §6.3–6.5.
**Дата:** 14 сентября 2026 г.
**Утверждает:** Начальник КТО / Главный конструктор Лунин В. В.

---

## 1. Главное правило

**Работать только по файлам из `Z:\04_ПРОИЗВОДСТВО` и только по последней ревизии.** Файлы из почты, флешек, мессенджеров и старые распечатки — не документ.

## 2. Где файлы

На компьютере участка открыть в Проводнике диск `Z:` — видны только `02_БАЗА` (эталоны стандартных изделий) и `04_ПРОИЗВОДСТВО` (выданные заказы). Права — только чтение.

```text
Z:\04_ПРОИЗВОДСТВО\
└── 250-АСТ_Школа12\                 папка заказа
    ├── Заявка_250-АСТ.xlsx          задание всем участкам
    ├── И01_Стол_L1400\
    │   ├── 02_PDF\                   чертежи
    │   ├── 03_ЧПУ\                   DXF (лист), IGS (труба)
    │   └── _Аннулировано\            старые ревизии — НЕ ИСПОЛЬЗОВАТЬ
    └── _Аннулировано\
```

Изделия `СТД` (стандартные): чертежи и файлы по ссылкам на листе «Комплект» заявки, из `Z:\02_БАЗА\<раздел>\<шифр>\02_PDF` и `03_ЧПУ`. Модели SolidWorks и папки `_Версии`, `_Аннулировано` не использовать.

## 3. Заявка — какой лист чей

| Лист | Участок |
| :--- | :--- |
| `1_Заготовка` | лазер, труборез, пилы: детали, материал, длина, количество, имя файла ЧПУ |
| `2_Сварка` | сварка: узлы, швы, контрольные диагонали |
| `3_Покраска` | малярный участок: RAL, поверхность, площадь |
| `4_Комплектация` | сборка и упаковка: крепёж, фурнитура, упаковка |
| `5_Списание` | ОМТС и склад |

## 4. Как читать имя файла

| Пример | Что значит |
| :--- | :--- |
| `250-АСТ-Т01.10.01 Столешница_Изм0.pdf` | чертёж, исходный выпуск |
| `250-АСТ-Т01.10.01 Столешница_Изм1.pdf` | тот же чертёж после первого изменения — **работать по нему** |
| `250-АСТ-Т01.10.01_S3_Ст3сп_x1.dxf` | лист толщиной 3 мм, сталь Ст3сп, 1 шт на изделие |
| `250-АСТ-Т01.20.01_Тр40х40х2_L1350_x2.igs` | труба 40×40×2, длина 1350 мм, 2 шт на изделие |

Если в папке оказались две ревизии одного файла — работать по большему номеру `_ИзмN` и сообщить технологу.

## 5. Порядок работы оператора ЧПУ

1. Скопировать нужные DXF или IGS из `03_ЧПУ\` в рабочую папку станка. Файлы в `Z:` не изменять.
2. Импорт:
   - лист — DXF в CypCut или CypNest, масштаб 1:1, мм;
   - труба — IGS в TubesT или CypTube.
3. Проверить размеры по чертежу PDF и количество по листу `1_Заготовка`.
4. Труба не распознаётся (сечение `0.00 x 0.00 x 0.00`) — не править вручную, вернуть технологу.
5. После резки отметить количество в сменном задании.

## 6. Если в документе ошибка

1. **Остановить операцию** по этой детали, если ошибка даст брак.
2. Сообщить технологу и Начальнику КТО: заказ, обозначение детали, в чём ошибка, фото.
3. Ждать исправленного файла `_ИзмN` в `04_ПРОИЗВОДСТВО` или письменного указания технолога.
4. Изготовленные по ошибочному документу детали отложить с биркой до указания о заделе.

Срочное исправление прямо в станке — только по распоряжению технолога или Начальника КТО, с записью: кто, что, когда. Затем конструктор оформляет изменение.

## 7. Извещение об изменении

Технолог сообщает об изменении и передаёт извещение (ИИ) или запись журнала заказа.

1. Прочитать указание о заделе: использовать, доработать или в брак.
2. Старые распечатки чертежей сдать технологу.
3. Работать по новым файлам `_ИзмN`.

## 8. Нельзя

- Работать по файлам из `_Аннулировано`, почты, флешек.
- Изменять файлы в `Z:\04_ПРОИЗВОДСТВО`.
- Самостоятельно исправлять размеры в программе резки без распоряжения технолога.
