# Инструкция И-04. Инженер-конструктор по металлу

> **Исторический документ** (архив 15.09.2026): инструкция к регламенту v2.2. Действующие — «Памятки по ролям простыми словами» в `05_Инструкции_по_ролям`.

**Для кого:** ведущие инженеры-конструкторы и инженеры-конструкторы направления «Металл».
**Основание:** Регламент КТО «Металл» v2.2 — часть 4, §6.4, §6.8.
**Дата:** 14 сентября 2026 г.
**Утверждает:** Начальник КТО / Главный конструктор Лунин В. В.

## 1. Ваша роль

Вы разрабатываете по заказам изделия направления `МЕТАЛЛ` и металлическую часть изделий `КОМБИ`: модели, чертежи, файлы для станков и техкарту на 1 шт.

| Стандартность | Что делать |
| :--- | :--- |
| `СТД` | ничего не проектировать — изделие берётся из эталона |
| `ТИПОВОЕ` | копия сборки эталона и отвязка изменяемых деталей (раздел 5, шаги 1–3) |
| `НЕСТАНДАРТНОЕ` | разработка с нуля: компоновочный эскиз в сборке, каждая деталь — отдельный файл; шаги 1–3 пропустить, остальные шаги раздела 5 выполнять |

Задачу, сроки и исполнителей вы видите в Битрикс24. Для `КОМБИ` вы делаете металлическую часть в папке `02_Металл\<изделие>\`; кто финализирует общую сборку и техкарту изделия, конструкторы решают сами и отмечают в задаче Битрикс24.

## 2. Рабочее место

| Что | Как должно быть |
| :--- | :--- |
| Диски | `Z:` — общая папка КТО; работа только с `Z:` |
| Подключение | только сетевой кабель |
| Инструментарий ЕСКД | установлен конфигуратором рабочего места; в SolidWorks есть вкладка «ЕСКД» и 9 кнопок SWplus |
| Папки на ПК | `C:\SW_Backup\`, `C:\SW_AutoRecover\`, `C:\SW_Rescue\`, `D:\Work\_Черновики\` |

Если чего-то нет — к сисадмину.

## 3. Ваши права

| Папка | Права |
| :--- | :--- |
| `Z:\02_БАЗА`, `Z:\01_БИБЛИОТЕКА`, другие заказы | только чтение |
| `Z:\03_ЗАКАЗЫ\<ваш заказ>` | чтение и запись — выдаёт Начальник КТО при назначении |

Сохранить не получается («только для чтения») — сначала контекстное меню «Кто открыл», затем Начальнику КТО.

## 4. Правила работы

1. Открывать сборки прямо с `Z:\03_ЗАКАЗЫ\…`. Копировать модели на `C:\` или `D:\` для работы нельзя; эксперименты — только в `D:\Work\_Черновики\`.
2. Перед открытием сборки заказа — Окно → Закрыть все.
3. Деталь открылась «только для чтения» — посмотреть «Кто открыл» и договориться; не сохранять под другим именем.
4. Сохранять часто: надстройка ЕСКД заполняет реквизиты при сохранении.
5. Не сохранять, пока по сети копируются большие файлы; дождаться окончания сохранения сборки.
6. Работа вне офиса — только через Pack and Go с разрешения Начальника КТО.

## 5. Разработка изделия

**Имена файлов:** деталь `250-АСТ-Т01.10.01 Столешница.sldprt`; сборка `250-АСТ-Т01.00 СБ Стол ученический L1400.sldasm`; чертёж — как модель. Без подчёркиваний; обозначение с цифрами.

**Шаг 1. Копия сборки эталона** (только `ТИПОВОЕ`).

1. Окно → Закрыть все; открыть эталон `Z:\02_БАЗА\…\СТД-СЛ120.00 СБ Стол ученический.sldasm`.
2. Файл → «Сохранить как» (не «как копию») → `…\И01_Стол_L1400\01_3D\` → новое имя; в «Дополнительно» ☐ «Включить все ссылочные компоненты».
3. MProp → очистить «Обозначение» и «Наименование» → Ctrl+S.

**Шаг 2. Отвязка детали — когда её нужно изменить.**

1. ПКМ по детали → «Сделать независимым» (все экземпляры — выделить Ctrl+клик).
2. **Сменить папку** на `…\01_3D\` папки изделия и дать имя по правилам.
3. Открыть новую деталь → MProp → очистить «Обозначение» и «Наименование» → Ctrl+S.
4. Только теперь менять размеры. Потянуло соседнюю деталь — повторить шаг 2.
5. Деталь внутри эталонного узла — сначала отвязать узел.

**Шаг 3. Чертежи отвязанных деталей.** Открыть чертёж эталонной детали → «Сохранить как» в папку изделия с новым именем → ПКМ по виду → «Заменить модель» → все виды → новая деталь → поправить оборванные размеры → Ctrl+S. Так же для сборочного чертежа.

**Шаг 4. Материал и покрытие.**

- Материал — только из `Библиотека_Материалов_ГОСТ` (дерево → Материал → Редактировать). Текст в графу 3 вручную не вводить. Нужного типоразмера нет — заявка куратору баз.
- Покрытие — свойство `Покрытие` в MProp, например «Порошковое, RAL 7035, шагрень», и пункт в ТТ.
- В деталях из проката — эскиз `Примечания` со справочным размером `RD1` (длина заготовки).

**Шаг 5. Безчертёжные детали.** Прямой отрезок трубы, полоса, пластина без отверстий: материал из библиотеки → сохранить → кнопка «Деталь БЧ» на вкладке ЕСКД. Чертёж не нужен, только файл для станка.

**Шаг 6. Файлы для производства.**

| Файл | Где | Как | Имя |
| :--- | :--- | :--- | :--- |
| PDF | `02_PDF\` | кнопка SaveAsPDF из чертежа | `250-АСТ-Т01.10.01 Столешница_Изм0.pdf` |
| DXF (лист) | `03_ЧПУ\` | ПКМ по развёртке → «Экспорт в DXF/DWG»; без линий сгиба; R2000, мм, 1:1 | `250-АСТ-Т01.10.01_S3_Ст3сп_x1.dxf` |
| IGS (труба) | `03_ЧПУ\` | Файл → Сохранить как → IGES; настройки из «Матрицы форматов ЧПУ»; система координат вдоль оси трубы | `250-АСТ-Т01.20.01_Тр40х40х2_L1350_x2.igs` |

SAT и STEP в `03_ЧПУ\` не кладутся.

**Шаг 7. Техкарта** `Техкарта_250-АСТ-Т01.00_на_1шт.xlsx` — 5 листов (заготовка, сварка, покраска, комплектация, списание).

**Шаг 8. Проверка перед сдачей.**

| № | Проверка |
| :---: | :--- |
| 1 | имена файлов по правилам |
| 2 | материал из библиотеки везде; «Синхронизировать» на вкладке ЕСКД без предупреждений |
| 3 | покрытие в свойстве и в ТТ |
| 4 | `RD1` в деталях из проката |
| 5 | БЧ оформлены кнопкой |
| 6 | покупные оформлены SProp, паспорт приложен |
| 7 | «Ссылки…» — только `Z:` |
| 8 | Ctrl+Q без ошибок; в чертежах нет оборванных размеров |
| 9 | спецификация SpecEditor, ТТ, PDF `_Изм0` |
| 10 | DXF и IGS на все новые детали |
| 11 | техкарта заполнена |
| 12 | задача в Битрикс24 переведена на проверку |

## 6. Ошибка при сохранении — спасение файла

Признаки: сообщение «Произошла ошибка при сохранении файла», зависание сохранения, пропал `Z:`.

1. **Не закрывать SolidWorks** и не нажимать «Не сохранять».
2. Файл → «Сохранить как копию» → `C:\SW_Rescue\` под тем же именем. Изменены и другие детали — так же для каждой.
3. Проверить `Z:` и файл: открывается ли, не нулевой ли размер.
4. Файл целый — Ctrl+S и работать дальше.
5. Файл испорчен — закрыть документ и восстановить: копия из `C:\SW_Rescue\` → копия из `C:\SW_Backup\` → «Предыдущие версии» файла в Проводнике.
6. В любом случае сообщить сисадмину.

## 7. Изменения после выдачи и дефекты

| Ситуация | Что сделать | Где записать |
| :--- | :--- | :--- |
| Ошибка в своём заказе, документы ещё не в `04_ПРОИЗВОДСТВО` | исправить | нигде |
| Ошибка в своём заказе, документы уже в `04_ПРОИЗВОДСТВО` | порядок ниже | `Журнал_изменений.xlsx` заказа |
| Деталь уже режут или варят, и будет брак | сразу мастеру и технологу, затем Начальнику КТО | потом — журнал заказа |
| Нашли дефект эталона | эталон не править | лист «Предложения» книги `Z:\02_БАЗА\_Извещения\Книга_регистрации_ИИ.xlsx` |
| Эталон не подходит только вашему заказу | «Сделать независимым» | нигде |
| Вашему заказу нужна прежняя ревизия изменяемого эталона | **до** правки эталона сделать детали независимыми | журнал заказа |

**Порядок изменения документов заказа после выдачи:**

1. Запись в `Журнал_изменений.xlsx`, лист «Изменения»: номер `Ж-250-АСТ-N`, дата, документ, было → стало, что делать с изготовленными деталями. Статус «В работе».
2. Если затронуты другое изделие, техкарта, покупные или срок — отметка Начальника КТО.
3. Изменить модель и чертёж → Ctrl+Q → «Синхронизировать» → таблица изменений в основной надписи («Изм.» — номер, «№ докум.» — `Ж-250-АСТ-N`, подпись, дата) → Ctrl+S.
4. Новые PDF, DXF, IGS с `_ИзмN`; прежние — в `_Аннулировано\` папки изделия.
5. Поправить техкарту; при изменении норм — сообщить технологу для пересвода заявки.
6. Нормоконтроль изменённого чертежа.
7. Начальник КТО или технолог заменяет файлы в `04_ПРОИЗВОДСТВО`; в журнале отметки «внесено в подлинники» и «в копии», статус «Внедрено».

## 8. Нельзя

- Работать с локальной копией заказа или открывать сборки по Wi-Fi и VPN.
- Править эталоны `02_БАЗА` и библиотеку.
- Вводить материал текстом вместо назначения из библиотеки.
- Перемещать и переименовывать файлы моделей Проводником.
- Менять документы, уже выданные в производство, без записи в журнале изменений заказа.
