# Инструкция И-02. Системный администратор

> **Исторический документ** (архив 15.09.2026): инструкция к регламенту v2.2. Действующие — «Памятки по ролям простыми словами» в `05_Инструкции_по_ролям`.

**Для кого:** системный администратор предприятия, обслуживающий NAS и рабочие места КТО.
**Основание:** Регламент КТО «Металл» v2.2 — часть 2 (§2.1–2.8), §3.2 шаг 8; ТЗ-01 для сетевой установки инструментария.
**Дата:** 14 сентября 2026 г.
**Утверждает:** Начальник КТО / Главный конструктор Лунин В. В.

## 1. Ваша роль

1. Synology NAS: тома, общие папки, SMB, права, снимки, резервные копии, ИБП.
2. Учётные записи и группы по распоряжению Начальника КТО.
3. Рабочие места КТО: сеть, питание, антивирус, SolidWorks, инструментарий ЕСКД.
4. Веб-доступ начальника производства.
5. Журнал ИТ: сбои сохранения, доступы, выпуски инструментария, учения по восстановлению.

## 2. Первичная настройка NAS (один раз)

| № | Где в DSM | Что сделать |
| :---: | :--- | :--- |
| 1 | Панель управления → Пользователь и группа → Группа | Создать группы: `kto_admins`, `kto_kurator`, `kto_metall`, `kto_korpus`, `kto_tech`, `production`, `prod_view` |
| 2 | Там же → Пользователь | Логин DSM = логин Windows сотрудника; пароль от 12 символов; Начальника КТО и себя — в `administrators` |
| 3 | Панель управления → Общая папка | `KTO`: том Btrfs, корзина только для администраторов, контрольная сумма данных. `KTO_ARHIV`: Btrfs, WriteOnce (Enterprise, 5 лет) |
| 4 | Общая папка → `KTO` → Изменить → Общие | ☑ «Скрывать подпапки и файлы от пользователей без разрешений» |
| 5 | Общая папка → Изменить → Расширенные разрешения | ☐ «Включить расширенные разрешения общего доступа» — **не включать** |
| 6 | Файловые службы → SMB | мин. SMB2, макс. SMB3; ☑ «Скрывать общие папки от пользователей без разрешений»; Opportunistic locking — по умолчанию; Durable handles — выключить, если после аварийного закрытия SolidWorks файлы остаются «только для чтения» |
| 7 | Внешний доступ | QuickConnect выключен; DDNS и проброс портов не настраиваются |
| 8 | Безопасность | брандмауэр: только подсеть офиса; автоблокировка после 5 неудачных входов; 2FA для `administrators`; учётная запись `admin` отключена |
| 9 | Snapshot Replication | папка `KTO`: снимки каждый час; хранить 48 часовых, 30 суточных, 12 недельных; неизменяемые снимки 7 дней; ☑ «Сделать снимки видимыми» |
| 10 | Hyper Backup | задача 1 — ежедневно 22:00 на внешний диск; задача 2 — еженедельно на второй NAS или облако вне здания |
| 11 | Оборудование → ИБП | безопасное выключение через 5 минут на батарее |
| 12 | Сеть | статический IP и DNS-запись `nas-kto`; в ярлыках и скриптах — только имя |

## 4. Сотрудники

**Приём** (по распоряжению Начальника КТО): создать пользователя → логин как в Windows → одна группа по должности. Личных записей в правах папок не создавать.

**Увольнение:** отключить учётную запись (не удалять); по листу «Доступы» журнала ИТ снять его явные записи со всех папок; сменить пароли общих учётных записей, если он их знал.

## 5. Веб-доступ начальника производства

Начальник производства просматривает эталоны `02_БАЗА` и выданные заявки `04_ПРОИЗВОДСТВО` в браузере, без сетевого диска и без права записи.

1. Пользователь начальника производства → только группа `prod_view`.
2. Права — по таблице раздела 3 (корень «только эта папка», `02_БАЗА` и `04_ПРОИЗВОДСТВО` — чтение для всех потомков).
3. Панель управления → **Привилегии приложений** (Application Privileges) → для каждого приложения → «Изменить» → «Группа» → `prod_view`:
   - **File Station** — «Разрешить»; при наличии варианта «По IP» — только подсеть офиса;
   - **DSM** (если такой пункт есть в списке) — «Разрешить», иначе вход в веб-интерфейс невозможен;
   - **SMB**, **AFP**, **FTP**, **WebDAV**, **Synology Drive** и прочие — «Запретить».
   При конфликте «Запретить» сильнее «Разрешить», поэтому пользователь `prod_view` не должен входить в другие группы.
4. Проверка: Привилегии приложений → «Просмотр разрешений» → пользователь и IP его ПК; затем вход с его ПК по адресу `https://nas-kto:5001`. Должны быть видны только File Station и папки `02_БАЗА`, `04_ПРОИЗВОДСТВО`; загрузка файла в них — отказ.
5. Выдать инструкцию И-09 и запись на листе «Доступы».

Доступ работает только из сети предприятия: внешний доступ NAS выключен. Доступ из дома — только после отдельного решения о VPN.

## 6. Рабочие места КТО

| Параметр | Требование |
| :--- | :--- |
| SolidWorks | одна версия и SP на всех ПК; обновление в один день после автотестов инструментария |
| Подключение | только провод; Wi-Fi и VPN для работы с `Z:` запрещены |
| Сетевая карта | Energy Efficient Ethernet — выкл., Green Ethernet — выкл.; ☐ «Разрешить отключение этого устройства для экономии энергии»; драйвер от производителя |
| Питание | план «Высокая производительность», сон при работе от сети — никогда |
| Диски | `Z:` → `\\nas-kto\KTO`, `Y:` → `\\nas-kto\KTO_ARHIV`, восстанавливать при входе |
| Антивирус | исключения: `SLDWORKS.exe`, `sldProcMon.exe`, `sldworks_fs.exe`, `swScheduler.exe`; папки `Z:\`, `D:\Work\`, `C:\SW_Backup\`, `C:\SW_AutoRecover\`, `C:\SW_Rescue\` |
| Локальные папки | `C:\SW_Backup\`, `C:\SW_AutoRecover\`, `C:\SW_Rescue\`, `D:\Work\_Черновики\` |
| Синхронизаторы | OneDrive, Dropbox, Synology Drive на `Z:` и `D:\Work` — нет |

**Инструментарий ЕСКД.** Целевой порядок — конфигуратор `Z:\00_ИНСТРУМЕНТЫ\_Инструменты_Конструктора\01_Настройки_SolidWorks\Настройка_Рабочего_Места_SolidWorks.exe` (после выполнения ТЗ-01). До этого — временный порядок:

```powershell
robocopy "Z:\00_ИНСТРУМЕНТЫ\_Инструменты_Конструктора" "D:\Work\_Инструменты_Конструктора" /MIR /XD .git build_temp runs /R:2 /W:5
```

Затем запуск конфигуратора или `УСТАНОВИТЬ_ЕСКД.bat` из `D:\Work\_Инструменты_Конструктора`. Перед запуском на ПК не должно быть папки `D:\Work\_Библиотека проектирования\_Toolbox`.

**Параметры SolidWorks, которые выставляются вручную** (Инструменты → Параметры → Настройки пользователя): среда для нескольких пользователей ☑, проверка файлов «только для чтения» каждые 5 минут; открывать ссылочные документы только для чтения ☑; искать внешние ссылки в местах расположения файлов ☐; «Справочные документы» — пусто; резервные копии — 3, папка `C:\SW_Backup\`, ☐ «в той же папке»; автовосстановление каждые 10 минут в `C:\SW_AutoRecover\`; Design Library `Z:\01_БИБЛИОТЕКА\`; Toolbox `Z:\01_БИБЛИОТЕКА\_Toolbox\`.

## 7. Ежемесячный контроль

| № | Проверка |
| :---: | :--- |
| 1 | снимки создаются, неизменяемые снимки активны |
| 2 | обе задачи Hyper Backup успешны |
| 3 | свободно не менее 25 % в `KTO` |
| 4 | нет пользователей вне групп; уволенные отключены |
| 5 | версии SolidWorks и SP совпадают на всех ПК |
| 6 | версия инструментария на ПК совпадает с опубликованной |
| 7 | нет файлов `~$*` старше суток в `03_ЗАКАЗЫ` (удалять только после проверки, что файл никем не открыт) |
| 8 | база Toolbox открывается без ошибок |
| 9 | лист «Сбои сохранения» разобран, пороги перехода на PDM не превышены |
| 10 | настройки сетевых карт не сброшены обновлением Windows (выборочно 3 ПК) |
| 11 | явные права пользователей — только у открытых заказов; временных прав на `02_БАЗА` с истёкшим сроком нет |

Ежеквартально: восстановить случайный заказ из снимка и из Hyper Backup во временную папку, записать время в журнал ИТ.

## 8. Сбой сохранения у конструктора

1. Конструктор уже спас файл по И-04 (раздел 6).
2. Запись на листе «Сбои сохранения»: дата, ПК, пользователь, файл, текст ошибки, чем восстановлен, потерянное время.
3. Разобрать причину: сетевой кабель и порт коммутатора, драйвер и энергосбережение сетевой карты, антивирус, питание, нагрузка на NAS в этот момент.

## 9. Нельзя

- Включать QuickConnect, проброс портов и внешний доступ без решения Начальника КТО.
- Устанавливать синхронизаторы на папки CAD-данных.
- Давать пользователям права «Администрирование» и выдавать доступ без распоряжения Начальника КТО.
- Удалять снимки и менять срок WriteOnce.
