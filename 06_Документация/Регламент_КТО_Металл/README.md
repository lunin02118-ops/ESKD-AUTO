# Регламент КТО «Металл»

Сквозной регламент организации данных, САПР и выпуска КД направления «Металл» ТОО «Троя»: версии, аудит, внешние заключения и сборка PDF.

## Состав папки

| Папка | Что внутри |
| :--- | :--- |
| [01_Действующая_редакция](01_Действующая_редакция/) | Регламент версии 2.2 (проект к утверждению): Markdown — источник, PDF — для рассылки и печати |
| [02_Аудит_и_заключения](02_Аудит_и_заключения/) | Аудит версии 1.0 с уточнениями от 13.09.2026; внешнее заключение по версии 2.0 (копия присланного файла, без правок) |
| [03_Архив_версий](03_Архив_версий/) | Версия 1.0 «Local-First» (объект аудита, строки совпадают со ссылками РЕГ:N), версии 2.0 и 2.1 |
| [05_Инструкции_по_ролям](05_Инструкции_по_ролям/) | Девять инструкций И-01…И-09 для каждой роли: от Начальника КТО до начальника производства (Markdown и PDF) |
| [04_Сборка_PDF](04_Сборка_PDF/) | Скрипт `md2pdf.py`: обложка, оглавление, колонтитулы, цветные блоки |

## История версий

| Версия | Суть | Основание |
| :--- | :--- | :--- |
| 1.0 | Локальная работа на `D:\CAD_WORKSPACE` с синхронизацией Synology Drive | исходный документ |

| 2.1 | Защита от порчи файлов при работе по сети без PDM, пороги перехода на PDM, IGS как единственный формат труборезов, скелет как основной способ моделирования | внешнее заключение, уточнение аудита |
| 2.2 | Права доступа к папкам и процедуры их выдачи Начальником КТО; изменения и ревизии по ГОСТ 2.503 для заказов и эталонов; архив закрытого заказа через Pack and Go; веб-доступ начальника производства; инструкции по ролям | запрос владельца 14.09.2026 |

## Правила ведения

1. Правки вносятся только в Markdown действующей редакции и инструкций; при изменении регламента проверяются инструкции затронутых ролей. PDF пересобирается скриптом, вручную не редактируется.
2. Новая редакция — новый файл с номером версии в имени; прежняя переносится в `03_Архив_версий` с пометкой «архивная редакция» в статусе.
3. Замечания и аудиты кладутся в `02_Аудит_и_заключения`. Присланные файлы хранятся без изменений.

## Сборка PDF

```powershell
python -m pip install --user markdown pymdown-extensions
python "06_Документация\Регламент_КТО_Металл\04_Сборка_PDF\md2pdf.py"
```

Без аргументов собираются все документы; выборочно — ключи `regl22` (действующая), `regl21`, `regl`, `audit`, `i01`…`i09` (инструкции). Нужен установленный Microsoft Edge.
