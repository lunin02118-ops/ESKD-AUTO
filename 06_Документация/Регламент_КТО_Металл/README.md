## Архив (`03_Архив_версий/`)

Регламенты v1.0, v2.0, v2.1, v2.2; `Аудиты_и_заключения/` — аудит v1.0, внешнее заключение по v2.0, аудит v2.2 и инструкций, описание работ по надстройке (заменено ТЗ-02); `Инструкции_v2.2/` — И-01…И-09 и комплект (заменены памятками). В начале каждого md — пометка «исторический документ».

## Правила ведения

1. Правки — только в Markdown, PDF пересобирается: `python 04_Сборка_PDF/md2pdf.py regl3 memos sa_task concept tz02 tz02plain` (без аргументов — всё; ключи архивных документов сохранены).
2. Новая редакция регламента — новый файл с номером и датой; прежняя — в архив с пометкой в первых строках.
3. Одно решение — одно место: правило в регламенте, «как нажимать» в памятках, «как сделано» в ТЗ. Не повторять текст между ними.
