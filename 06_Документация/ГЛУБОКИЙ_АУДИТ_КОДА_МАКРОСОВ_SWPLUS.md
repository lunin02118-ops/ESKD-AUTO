Общий объем исходного кода пакета составляет **более 100 000 строк** на языке Visual Basic for Applications (VBA 7.1) с интеграцией Windows API и SolidWorks COM API.

### 2.1. `SProp.swp` — Свойства Стандартных и Покупных Изделий (Standard & Purchased Parts)
> [!IMPORTANT]
> **Уточнение назначения:** Макрос `SProp` **НЕ является макросом листового металла** (буква `S` означает *Standard / Subcontracted parts*). Его истинное предназначение по коду — паспортизация стандартных (крепеж, подшипники) и покупных изделий для корректного попадания в соответствующие разделы **Спецификации (СП)** и **Ведомости покупных изделий (ВП)** по ГОСТ 2.106.

#### Архитектура модулей:
- `FrmSProp.frm.bas` (1 116 строк) — логика формы;
- `FrmSProp_Pref.frm.bas` (182 строк) — конфигурация сопоставления свойств;
- `SProp_run.bas.bas` (180 строк) — точка входа `main()`;
- `SProp_top.bas.bas` (128 строк) — удержание окна поверх всех окон (WinAPI `SetWindowPos`).

#### Ключевые переменные и структура данных:
```visualbasic
Dim prpDescription As String       ' Наименование для спецификации
Dim prpDescriptionVP As String     ' Наименование для Ведомости покупных (ВП)
Dim prpNumberDocVP As String       ' Номер документа на поставку (ГОСТ / ТУ)
Dim prpVendorVP As String          ' Поставщик изделия
Dim prpProductCodeVP As String     ' Код продукции (ОКП / ОКПД2)
Dim prpRemarkVP As String          ' Примечание ВП
Dim prpSection As String           ' Раздел спецификации ("Стандартные изделия" / "Прочие изделия")
```

#### Механизм генерации наименования по конфигурациям (`ChkConfig_Click`):
Если изделие имеет множество конфигураций (например, болт М6х20, М6х25, М8х30):
```visualbasic
' Автосборка наименования из 3 частей:
' TxtPre ("Болт ") + TxtParam1 + $PRP:"SW-Configuration Name" + TxtPost (" ГОСТ 7798-70")
sName = TxtPre.Text & TxtParam1.Text & "$PRP:" & Chr$(34) & "SW-Configuration Name" & Chr$(34) & TxtPost.Text
swModel.AddCustomInfo3 sConfigName, prpDescription, swCustomInfoText, sName
```
Это ключевая фишка Leon: **одна 3D-деталь с 100 конфигурациями автоматически отдает в спецификацию точное ГОСТ-наименование для каждой конфигурации без ручного ввода!**

### 2.2. `MProp.swp` — Ядро паспортизации 3D-модели (Model Properties)
- **Объем:** 23 047 строк VBA.
- **Главный класс / форма:** `FrmMProp.frm.bas` (7 812 строк).

#### Как работает точка входа `MProp_run.bas`:
1. Проверяет тип активного документа:
   ```visualbasic
   Set swModel = swApp.ActiveDoc
   If swModel.GetType = swDocDRAWING Then
       ' Интеллектуальный режим: если запущен из чертежа, сам находит 3D-деталь!
       Set swDraw = swModel
       Set swView = swDraw.GetFirstView.GetNextView
       Set swModel = swView.ReferencedDocument
   End If
   ```
   *Конструктор может нажать MProp прямо в чертеже — макрос сам откроет свойства ассоциированной модели детали!*
2. Считывает геофизические свойства через SolidWorks API:
   - `swModel.Extension.CreateMassProperty` -> вычисляет точную массу, объем, площадь поверхности и центр тяжести;
   - Записывает строковое значение массы в свойство `Масса` с округлением по ЕСКД.
3. Интеграция с материалами:
   - Считывает `swMaterialPropertyDensity` (плотность) и `swMaterialPropertyCrosshatchPattern` (штриховка);
   - Управляет полями `MARKA_MATERIAL`, `SORTAMENT`, `SHAPE`, формируя строку для графы 3 штампа.
4. Конфигурационная матрица:
   - Позволяет привязать свойства к выбранной конфигурации (`swModel.CustomInfo2(sConfigName, ...)`), ко всем конфигурациям оптом или к уровню файла (`""`).

### 2.3. `Master.swp` — Интеллектуальный менеджер форматок чертежа
- **Объем:** 7 891 строк VBA.
- **Главная форма:** `FrmMaster.frm.bas`.

#### Алгоритм автоматического распознавания формата (`Sub Detect`):
Макрос обращается к API чертежного листа `swSheet.GetProperties`:
```visualbasic
vProps = swSheet.GetProperties
PaperWidth = Round(vProps(5) * 1000, 1)   ' Перевод в миллиметры
PaperHeight = Round(vProps(6) * 1000, 1)
```
И сопоставляет с ГОСТ-матрицей:
- $210 \times 297$ мм $\rightarrow$ `A4-P` (вертикальный)
- $297 \times 420$ мм $\rightarrow$ `A3-A` (альбомный)
- $420 \times 594$ мм $\rightarrow$ `A2-A`
- $594 \times 841$ мм $\rightarrow$ `A1-A`
- $841 \times 1189$ мм $\rightarrow$ `A0-A`
- Кратные форматы: А4х3 ($297 \times 630$), А4х4 ($297 \times 841$), А3х3 ($420 \times 891$) и т.д.

#### Алгоритм безопасной подмены основной надписи:
1. Фиксирует существующие чертежные виды (`swDraw.GetFirstView`);
2. Включает контекст листа: `swDraw.EditSheet`;
3. Загружает файл `.slddrt` из каталога, прописанного в `Master.ini`, методом:
   ```visualbasic
   swDraw.SetupSheet5 SheetName, PaperSize, TemplateIn, Width, Height, False, TemplatePath, ...
   ```
4. Если на листе присутствует знак шероховатости, пересчитывает координаты и перемещает блок `Roughness` в новый правый верхний угол;
5. Выполняет форсированную перерисовку: `swDraw.GraphicsRedraw2` и `swDraw.ForceRebuild3`.

### 2.4. `SpecEditor.swp` — Полномасштабный генератор спецификаций (33 782 строки)
Это самый объемный и сложный компонент пакета, заменяющий встроенный генератор SolidWorks на строгий алгоритм по ГОСТ 2.106-96.

#### Внутренний пайплайн обработки данных:
```
[Сборка .SLDASM] ──> [swTable.BomFeature] ──> [Парсинг свойств компонентов]
                           │
                           ▼
          [Классификатор разделов ЕСКД SpecEditor_Sections.txt]
          ├── 1. Документация (СБ, ВП, ТУ)
          ├── 2. Сборочные единицы
          ├── 3. Детали
          ├── 4. Стандартные изделия (SpecEditor_Groups.txt)
          ├── 5. Прочие изделия
          └── 6. Материалы (SpecEditor_MaterialGroups.txt)
                           │
                           ▼
          [Естественная числовая сортировка ГОСТ (М6, М8, М10)]
                           │
                           ▼

                           │
                           ▼
          [Расчет сквозных позиций -> swBomFeat.KeepCurrentItemNumbers = True]

                           └──> Синхронизация выносок на сборочном чертеже!
```

### 2.5. `RecordDimM.swp` — Перехватчик событий размеров и допусков
- **Объем:** 1 776 строк VBA.
- **Архитектура:** Построен на событийной модели через класс `ClassRecordDimM.cls.bas`.
- Подписывается на события SolidWorks `WithEvents`:
  - `MyDrw_NewSelectionNotify` (выбор в чертеже);
  - `MyPart_NewSelectionNotify` (выбор в детали);
  - `MyAssem_NewSelectionNotify` (выбор в сборке);
  - `MyDrw_DimensionChangeNotify` (изменение размера).
- Форма `FrmRecordDimM` содержит таблицы квалитетов ЕСКД (H7, H8, H9, h6, h8, js14, g6, f7...) и при клике рассчитывает верхнее и нижнее отклонение по ГОСТ 25346 / ГОСТ 25347.

### 2.6. `Roughness.swp` — Неуказанная шероховатость
- **Объем:** 366 строк VBA.
- Определяет габариты активного листа чертежа через `swSheet.GetProperties`.
- Создает точку вставки в правом верхнем углу через `swMathUtil.CreatePoint` и вставляет параметрический блок `Znak1..5.SLDBLK` методом `swSketchMgr.MakeSketchBlockFromFile`.

---

### 2.7. `SaveAsPDF.swp` — Пакетный публикатор КД
- **Объем:** 9 726 строк VBA.
- Считывает атрибуты: `Обозначение` (`Number`), `Наименование` (`Description`), `Изм.` (`Revision`).
- Очищает строку от запрещенных символов файловой системы.
- Для каждого листа чертежа определяет персональную ориентацию и размер бумаги через WinAPI `GetProfileStringA` и `swDraw.PageSetup`.
- Пакетно генерирует векторные PDF.

## 3. Рекомендации по совместимости с SolidWorks 2025

1. **WinAPI 64-bit:**  
   В модулях оконного управления `*_top.bas` уже внедрен блок условной компиляции `#If VBA7 Then Declare PtrSafe ...`, что обеспечивает совместимость с 64-битными версиями Windows и SolidWorks.
2. **Пути в `Master.ini`:**  
   Программа `CAD_Workstation_Configurator.py` теперь автоматически переписывает локальные пути на актуальные сетевые UNC-пути `\\Home-pc\...`, исключая любые сбои поиска форматок.
3. **Двухэтажная дробь сортамента ГОСТ:**  
   Благодаря тегу `<STACK>`, внедренному в нашу библиотеку материалов, `MProp` автоматически транслирует двухэтажную дробь ГОСТ в Графу 3 штампа чертежа.
