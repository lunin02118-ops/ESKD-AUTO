## 2. Имя заказа
`<№>[-<п>]_<Код>_<Объект>_<Город>`
- под-номер через дефис: `106_1`, `106.1` → `106-1`;
- Код: `Т`, `Ал`, `Аст`, `ВЭД` кириллицей (`АСТ`→`Аст`, `АЛ`→`Ал`, латинская T → `Т`); нет — поле с `_` опускается;
- Объект коротко, без `№ « » , . ! + #`, без двойных и концевых пробелов;
- Город без «г», `Алматы`; нет — опускается;
- ≤ 40 знаков. Пример: `АСТ_ 207-1_ КГМ. ДИЖИТАЛ_ г Астана` → `207-1_Аст_КМГ Диджитал_Астана`.

## 3. Папка заказа (создавать ВСЕ папки, даже пустые)
```
<заказ>\
│  СЗ*, Служебная*, *Сводная*, Заявка*        корень
├─ 01_Исходные данные\
│    Документы\
│    Фото и видео\
│    Переписка\
│    На согласовании\
├─ 02_Металл\
│    И<nn>_<шифр>_<наименование>\
│       01_3D\
│       02_PDF\
│       03_ЧПУ\Лазер_Лист\
│       03_ЧПУ\Труборез\
│       04_Сопроводительная документация\
│       _Аннулировано\
│       Изменения.xlsx, ТЗ позиции, деталировки/калькуляции металла; Ведомость_<шифр>.xlsx — старый образец
│       04_Сопроводительная документация\ЛЗК_<шифр>.xlsx — книга ЛЗК (ведомость, участки, расход)
├─ 03_Корпус\
│    01_Модели\  02_Схемы сборки\  03_Раскрой\  04_Ведомости\  05_Визуализация\  _Аннулировано\
└─ 04_Войлок\
     01_Чертежи\  02_ЧПУ\  _Аннулировано\
```
Папок `05_…`–`08_…` нет. Ничего не лежит прямо в `03_ЧПУ` — только в `Лазер_Лист` / `Труборез`.
Нераспознанное — временно в `<заказ>\_Не разобрано\` (металл без изделия — `02_Металл\И00_Не разобрано\` с той же раскладкой), с вопросом пользователю.

## 4. Производство

С 18.09.2026 (ТЗ-04) отдельной папки производства нет: цех читает `02_PDF` и `03_ЧПУ` папки изделия, листы участков —
`02_PDF\ЛЗК_<шифр>_<участок>.pdf`, отметка выдачи — `_Выдано_<дата>.txt` в папке изделия. Существующие
`_Производство\<заказ>` — история, их не удалять и не пополнять. Списание старых заказов — в корень заказа.
Только копии; отметки `_Выдано_*.txt` не создавать; корпус и войлок сюда не копируются.

## 6. Изделия и шифры

**Шифр** — обозначение главной сборки без нулевых хвостов (`.00.00.000`, `.00.000`, `.000`):

| Главная сборка | Шифр |
|---|---|
| `ТС-85.00.00.000 Кровать` | `ТС-85` |
| `85T.СМ.00.000 Кровать одноместная` | `85T.СМ` |
| `СУAt-05.00.000 Стол учителя` | `СУAt-05` |
| `61-1.05.01.000 Проставка` | `61-1.05.01` |
| `ПА.00.000` (детали `ПА00.001`) | `ПА` |

- Файл принадлежит изделию, если его обозначение начинается с шифра (самое длинное совпадение); `ПА00.001` считается как `ПА.00.001`.
- Главная сборка — `.a3d/.sldasm` с нулевым хвостом; при нескольких — та, на которую не ссылается другая (MCP).
- Шифр в имени папки — **буква в букву как в файлах** (латиница/кириллица не исправляется; смешение отметить).
- `И<nn>` — номер позиции в служебной записке; наименование — из СЗ (≤ 40 знаков всё имя, сокращать наименование).
- Нет шифра (например, только PDF «Стол учителя») — изделие по наименованию; в заказе одно изделие — всё металлическое туда.
- Существующая папка изделия/позиции (`СУAt-05 Стол учителя`, `2.12_Стул…`, `641-1 Островной`) — одно изделие.
- Сборку с деталями и чертежами класть в `01_3D` одного изделия целиком; подпапки относительно сборки (`3D\Скоба`) сохранить.

## 7. Версии и дубли
- Одинаковое имя, разное содержимое: актуален файл из «Готово»/«Запуск»/более новый по дате; остальные — `_Аннулировано`.
- Одинаковая контрольная сумма — один экземпляр, остальные — `_Аннулировано\_дубли`.
- Суффикс `_ИзмN` — более поздняя ревизия; файл без суффикса при наличии `_Изм1` — `_Аннулировано`.

## 8. Спорные случаи
- **СЗ лежит в «Корпус»** — всё равно в корень заказа.
- **Сводная заявка с номером чужого заказа** (`641_Сводная…` в папке 105) — не переносить в другой заказ, спросить.
- **Файлы другого заказа** (`159_Аст_Трубка…` в папке 104) — оставить на месте разбора, спросить.
- **Позиции с ТЗ без файлов** — создать `И<nn>` с одним ТЗ.
- **Только `.bak.bdf`, основного нет** — это рабочий файл: `03_Корпус\01_Модели`, в вопросы.
- **Картинка: схема или фото?** — «схем», «сборк», номер позиции в начале (`1Схема…`), путь «Корпус» → схема; WhatsApp/IMG → фото; иначе вопрос.
- **PDF без шифра в папке «Металл»** — чертёж металла, если в заказе одно изделие; иначе по наименованию; иначе `И00_Не разобрано`.
- **Длинный путь (> 240)** — сократить имена **папок** (не файлов); не получается — вопрос.
