УСТАНОВКА DREW НА НОВУЮ МАШИНУ - «ИЗ КОРОБКИ» (АДАПТИВНЫЙ РЕЖИМ)
==============================================================
ПРОСТОЙ ПУТЬ (1 клик):
  Двойной клик по УСТАНОВИТЬ_DREW.cmd
  - Если запущен обычным пользователем (без прав админа) -> автоматически
    устанавливается для текущего пользователя в AppData. Права администратора НЕ требуются!
  - Если запущен от имени администратора (ПКМ -> «Запуск от имени администратора») ->
    устанавливается для всех пользователей в Program Files.

  Установщик сам: разместит файлы, настроит реестр COM и SOLIDWORKS Add-in
  и откроет окно АКТИВАЦИИ. Дальше: «Скопировать» ключ железа -> офицеру ->
  получить код DREW-XXXXX-... -> вставить -> «АКТИВИРОВАТЬ» -> SOLIDWORKS.

РУЧНОЙ ПУТЬ (если тихая установка нежелательна):
  1. При наличии прав админа: установить Drew_4.3.0.0.msi.
  2. Закрыть SOLIDWORKS. Скопировать 2_комплект_издания\bin\ в целевую папку
     (в C:\Program Files\CAD Booster\Drew\ или в %LOCALAPPDATA%\CAD Booster\Drew\).
  3. Запустить 3_активация\АКТИВИРОВАТЬ_DREW.cmd и активировать кодом.

ВАЖНО: код выдаётся ОДНОЙ машине (по ключу железа); на каждую машину -
свой код. Смена материнской платы = новый ключ = новый код. Всё офлайн.
